# 常見問題

## 鍋和灶台

**Q：鍋裡有湯，灶台為什麼不點火？**
看三件事：① 灶膛裡有沒有燃料（右鍵磚身開啟看）；② 鍋是不是坐在灶台上；③ 湯倒進去了沒有（沒湯的鍋不點火）。點火後鍋會冒熱氣，湯面會沸騰。

**Q：灶台點著火，但是燃料沒少？**
正常。只有**鍋裡有生食材要煮**時才耗燃料，只有湯沒菜是「空燒」，不耗燃料（見[灶台與火鍋](hotpot.html#fuel)）。

**Q：東西放不進鍋裡。**
鍋裡該放**能下鍋的生食材**，熟食、辣椒 / 小米辣或被列入 `orients_hotpot_chronicles:not_pot_ingredient` 標籤的物品放不進去。另外對著的那大格滿了（9 小格）也放不進去，換個大格試試。

**Q：想換湯底怎麼辦？**
拿**空桶右鍵鍋**把湯舀回桶裡（有菜先取出來）。菌湯要用碗舀，而且鍋裡沒菜才行。

**Q：鍋裡的東西怎麼都不熟？**
- 鍋是不是「冷鍋」（不在點著的灶台或營火上）？冷鍋不會煮熟。
- 火力：木頭 ×0.65、煤炭 ×1.0、岩漿桶 ×1.6；湯底：高湯最慢、紅湯最快。木頭燒 + 高湯會很慢。
- 食材烹飪時間不同：整塊牛肉 5 秒，肥牛捲 2.5 秒，吊龍約 1 秒多（見[配方大全](recipes.html)的烹飪與鍋中專煮表）。

**Q：吃東西突然反胃了。**
在開啟懲罰（完整模式預設）時，吃了**冷鍋**裡的東西有 30% 機率反胃 15 秒。喝一瓶**植物蛋白飲料**、一碗**清湯**或沾**醋**能解；若不喜歡這類懲罰，可在模組設定頂部切換到**精簡模式**，或在「▸ 自訂細項」關閉「冷鍋反胃與辣懲罰」。

**Q：放高灶台提示放不下 / 有鍋時點不到灶膛？**
高灶台佔頭頂一格，把上面一格清空。放上鍋後，如果只想開啟灶膛添燃料，直接右鍵**高灶台下半截磚體**即可穩定開啟。

**Q：鍋怎麼收起來？**
灶台上的鍋：空手 **Shift + 右鍵**，整鍋連湯帶菜進背包，放下原樣恢復；直接挖也行，碎屑和掉落物會按鍋的位置出現在鍋所在高度。

## 桌椅、備菜架和餐具

**Q：以前版本的 40 張木頭/石料火鍋桌去哪了？怎麼做新外觀？**
`0.3.1-alpha` 起全部收束為通用**火鍋桌**（{{i:hotpot_table}}）和**高火鍋桌**（{{i:tall_hotpot_table}}）。升級舊存檔時已擺放和背包裡的舊桌會自動遷移並保留原外觀。想換材質時，**手拿任意實心不透明方塊直接右鍵桌面（上半）或底座（下半）**即可 1 進 1 出無損換裝（潛行空手拆出），見[桌子、備菜架與凳子](tables.html#swap_materials)。

**Q：凳子坐不上去。**
空手（或手裡拿不是方塊的東西）右鍵。兩個人之間要隔一整格；旁邊有人就挪一格坐；手持模組作物也能直接坐凳子。

**Q：盤子放不下 / 一格擺不下更多了。**
盤子不能重疊。小碟一格最多 5 個，長盤一格 2 個，方盤一格 1 個，混放看佔的地方。

**Q：高桌上的東西點不中。**
模組已經處理了：準星對著桌面上的盤子也能選到。真點不中，往旁邊一點或蹲下試試。

**Q：想把桌上的盤子整個拿走。**
空手右鍵盤子整盤拿起來；挖也可以，只會挖對著的那一個。

## 食材、果樹與加工

**Q：怎麼得到毛肚、牛脊肉和生雞爪？**
殺牛或哞菇掉**毛肚**（25% 額外掉**牛脊肉**）；殺成年雞有 50% 機率掉 1～2 個**生雞爪**（著火死掉熟雞爪）。

**Q：為什麼打原版橡木樹葉不掉柳橙了？黃豆、小蔥、香菜怎麼得？**
`0.3.1-alpha` 起新增了**獨立柳橙樹**與 **9 種可種植作物**：
- **柳橙**：在森林、繁花森林、平原、草甸與叢林找到自然生成的矮柳橙樹（或用柳橙樹苗種一棵），等柳橙葉長成掛果後直接空手右鍵採摘。
- **9 種作物**（小蔥、香菜、黃豆、大蒜、番茄、辣椒、花生、青菜、折耳根）：可在對應群系野外採**野生植株**，也可直接拿成品對著**耕地右鍵播種**（支援骨粉）；開啟「獨立作物替代打草」（完整模式預設）時，打草僅保留 **2%** 稀疏找種兜底。如果喜歡舊版高掉率打草，在設定裡關閉該選項或切換至**精簡模式**即可恢復。

**Q：小石磨怎麼用？豆漿怎麼自動流進開口大木桶？**
1. 拿 2 顆黃豆右鍵放進小石磨頂斗，再拿水桶倒水蓄能（1 桶水預設磨 3 次），空手連續右鍵推磨 4 圈即可磨出豆漿（乾磨花生、辣椒、大蒜則不用倒水）。
2. 如果你把**空的開口大木桶（{{i:wooden_vat}}）緊挨著小石磨出料口正前方**擺放，最後一圈磨完時豆漿會自動從磨嘴流進木桶（不用拿空桶接來接去）；若單獨擺放石磨，用**空鐵桶**右鍵磨槽盛出{{i:soymilk_bucket}}再倒進大木桶即可。大木桶裡加入{{i:brine_bottle}}並蓋上{{i:wooden_press_lid}}，等 4 秒壓出 2 塊冷豆腐；精簡模式（或關閉「細緻豆腐工序」）可直接用黃豆 + 水桶合成冷豆腐。

**Q：砧板放不上東西。**
能切或能搗的生食才可放上砧板：切配有生牛肉、生羊肉、生豬排、牛脊肉、馬鈴薯、冷/熱豆腐、蝦、火腿腸、辣椒、蓮藕、生魷魚、折耳根與生雞爪；搗製有生肉（牛/豬/羊/鱈/鮭）、大蒜、蝦仁、花生與折耳根。熟火腿腸以外的熟食與成品不可重複下板。

## 光影、畫質與模組相容

**Q：開了光影和效能最佳化模組，柳橙樹、作物和鍋灶有什麼特別適配？**
- 核心硬表面、鍋灶（含火口餘燼自發光）、餐具與湯面內建 `LabPBR 1.3` 法線/高光副圖（`_n` / `_s`），兼顧原版、Sodium 與 Iris / BSL 等光影表現；
- 柳橙樹葉遵循原版「**流暢 / 高品質**」畫質開關切換實心林蔭底與透明鏤空，並自動向 Iris 光影注入柳橙樹葉、柳橙樹苗、9 種作物與野生植株的植物搖曳映射。

**Q：安裝了 JEI、REI 16、Jade 或 Axiom 等模組能相容嗎？**
完全相容：JEI 與 **REI 16**（含 Fabric / NeoForge）可正常展示火鍋涮煮、砧板切配、擀麵棍搗製、小石磨研磨與開口大木桶壓製五類配方及沾醬台原料表避讓區；**Jade**（含 1.20.1 Jade 11.x 修復）可查看鍋內湯底/進度/辣度、分部位桌架材質、備菜架槽位數量與上限及木桶液量；創造模式物品欄左側也會自動避讓 Axiom 等外置工具列。

## 存檔和版本

**Q：舊存檔能直接升級到 0.3.2-alpha 嗎？**
- `0.2.2-alpha` / `0.3.0-alpha` / `0.3.1-alpha` 存檔與設定可**直接平滑升級**：40 種舊預設桌在區塊/背包載入時自動升級為通用火鍋桌，舊備菜架槽位存檔（`Slot0..Slot5`）原樣保留相容，舊設定 `soaked_*` 等廢棄鍵靜默清理零警告；
- 若是從 `0.1.0-alpha.1` 等極早期版本跨越升級，請**務必先備份存檔**。

**Q：這個模組留了哪些聯動/資料包介面？**
- 方塊標籤 `orients_hotpot_chronicles:heat_sources` 裡的方塊都能當鍋的熱源；`#not_pot_ingredient` 禁止物品下鍋；
- 支援透過資料包自訂/覆蓋**湯底**（`recipe/soup/`）、**沾醬**（`recipe/seasoning/`）、**鍋內煮法**（`pot_boiling`）、**搗製**（`pounding`）、**石磨/木桶加工**（`stone_mill` / `wooden_vat`）、**音遊曲譜**（`hotpot_tracks/*.json`）及**備菜架堆疊與陳列規則**（`prep_rack_rules/*.json`，亦支援子模組啟動期呼叫 `HotPotHooks.registerRackRule`）。

**Q：1.20.1、26.1.x、26.2、26.3 和 1.21.1 有什麼區別？**
0.3.2-alpha 延續五大版本線同步策略，**1.21.1（Fabric / NeoForge）、1.20.1（Fabric / Forge）、26.1.x（Fabric / NeoForge）、26.2（Fabric / NeoForge）與 26.3（Fabric / NeoForge）** 全部同步更新，玩法與內容一致。詳見[下載、安裝與回報](install.html#ports)。

## 完整/精簡模式與數值設定 {#config}{{since:0.2.0-alpha}}

**Q：覺得工序太多想輕鬆點玩，能簡化嗎？能改數值嗎？**
能。直接從**模組列表**（Fabric 需裝 Mod Menu，NeoForge / Forge 原生自帶）選中本模組點「**設定**」：
- **模式切換（0.3.1-alpha 起）**{{since:0.3.1-alpha}}：介面頂部提供「**完整模式 / 精簡模式**」一鍵切換與「▸ 自訂細項」6 個獨立開關（`細緻豆腐工序`、`冷鍋與辣懲罰`、`獨立作物替代打草`、`即時小遊戲`、`備菜架換材質`、`精簡模式折疊指南次要細節`）；切換模式**絕不會刪除任何物品或損壞存檔**，遊戲內火鍋指南底部會顯示目前模式並聯動折疊對應說明與配方。管理員也可執行 `/orientshotpot mode [full|simple]`。
- **直接改設定檔**：也可編輯 `config/orients_hotpot_chronicles.json` 並由管理員執行 **`/orientshotpot reload`** 熱重載，無需重啟即生效；舊版本遺留廢棄鍵會自動靜默清理。
- **多人服**只改伺服器端，玩家進服、模式切換和重載時會自動同步。
- 某一項寫錯（不是數字、超範圍、鍵名拼錯）只回退那一項並警告；整個檔案寫壞就全部用預設值，**壞檔案原樣保留**方便修。
- 配方、曲譜與備菜架規則（`prep_rack_rules/*.json`）用資料包改，再執行原版 `/reload`；`loot.*` 掉率修改後同樣需執行一次原版 `/reload` 才會按新機率重建戰利品池。
- 重載後，**已經下鍋的食材保留已煮的進度**，剩餘時間按新數值重算；`cooking.items.<物品>` 只管本模組自己的食材，原版和其他模組的食材按它們自己的烹飪配方煮。

### 設定介面怎麼用 {#screen}

{{since:0.2.2-alpha}}介面頂部為**模式預設欄與自訂細項抽屜**，下方分**常用**和**進階**兩張頁籤，開啟時停在**常用**：

- **常用**只放玩家最常動的幾項——最上面是**煙霧粒子強度**滑桿（另有 0% / 50% / 100% 三個快捷檔），下面是**煤炭檔灶火功率**（整體涮煮快慢的總閘）、**涮煮兜底時間**，以及**紅湯 / 清湯 / 高湯的加熱倍率**。
- **進階**把其餘全部按分類收進 **19 個可折疊分組**（模式與機制、作物與果樹、食材加工、備菜架、桌架換材質、即時小遊戲、涮煮時間、食材涮煮時間、湯底加熱倍率、燃料檔位、湯碗、沾醬、飲料、食物營養、圍鍋回血、冷鍋反胃、碰杯乾杯、紅湯辣度、戰利品掉率），預設收起，點分組標題展開。
- **改數值**：每行是 `- 數值 單位 +`。點一次走一步，**按住 Shift 點一次走 10 步**；**點數值框可以直接敲數字**，敲成非數字或超出範圍會**標紅，且不讓儲存**。
- **單位**：時間按 tick 顯示（20 tick = 1 秒，夠寬時後面還會折算成秒），倍率寫「倍」，飢餓、經驗寫「點」，效果等級寫「級」，半徑距離寫「格」。
- **單項 / 全部恢復**：改過的行右邊會出現 **↺** 單項重置；底部「恢復預設」點一次會變成「再點一次確認」，4 秒內再點一次全部恢復（並重置粒子強度為 100%）。
- **儲存失敗提示**：寫不進設定檔時介面停在目前頁說明原因；原檔案損壞時先備份成 `orients_hotpot_chronicles.json.broken-<時間>` 再儲存並提示備份名。

## 資料包 / 子模組加湯底和沾醬 {{since:0.3.0-alpha}} {#custom_soup_sauce}<!--清单#154-->

自 **0.3.0-alpha** 起，除了修改內建數值和鍋內煮法，湯底和沾醬也支援透過資料包或 Java 子模組新增與覆蓋：

- **資料包配方路徑與重載**：在資料包中放置 `data/<命名空間>/recipe/soup/<名稱>.json`（配方類型 `orients_hotpot_chronicles:soup_base`）可新增或覆蓋湯底，放置 `data/<命名空間>/recipe/seasoning/<名稱>.json`（配方類型 `orients_hotpot_chronicles:seasoning`）可新增或覆蓋沾醬；最終登記 ID 會自動剝去 `soup/` 或 `seasoning/` 目錄前綴（例如 `<命名空間>:<名稱>`）。儲存後執行 `/reload` 即可熱重載，連線時伺服器端會自動同步到用戶端（不列入原版配方書）。
- **覆蓋優先級**：資料包只需填寫要調整的部分欄位就能覆蓋內建湯底或沾醬；但玩家在 `config/orients_hotpot_chronicles.json` 或設定介面中**顯式修改過的內建數值**優先級最高，不會被資料包覆蓋（設定 > 資料包 > 程式碼預設）。第三方命名空間條目只由資料包或子模組定義，不讀寫本模組內建設定檔。
- **通用湯碗與外觀著色**：子模組可為新增湯底提供專屬碗物品與湯面貼圖（`assets/<ns>/textures/block/hot_pot_top_<path>[_boiling].png`）；沒有專屬碗物品的湯底盛出時會裝入{{i:soup_bowl}}通用湯碗 `orients_hotpot_chronicles:soup_bowl`，透過 `orients_hotpot_chronicles:soup` 資料元件記錄湯底 ID 並繼承對應效果。純 JSON 資料包無需額外貼圖，鍋面會按 `screen_colors.base`、沸騰氣泡按 `bubble_colors.body` 著色渲染清湯基底；若之後移除資料包或子模組，已有方塊和碗中的原始 ID 資料會保留，介面與湯面顯示為未知佔位。
- **子模組 Java 登記**：附屬模組可在啟動註冊凍結前呼叫 `Soups.register(...)` 與 `Seasonings.register(...)` 註冊條目，詳細欄位與格式見倉庫內的 `mod/docs/开放登记说明.md`（`mod/content/materials.json` 僅作本模組內建材質與內建湯底靜態產生器的唯一事實來源，無需修改）。
