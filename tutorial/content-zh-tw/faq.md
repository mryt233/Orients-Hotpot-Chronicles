# 常見問題

## 鍋和灶台

**Q：鍋裡有湯，灶台為什麼不點火？**
看三件事：① 灶膛裡有沒有燃料（右鍵灶台磚身打開看）；② 鍋是不是真的坐在灶台上；③ 湯是不是倒進去了（沒有湯的鍋不會點火）。點火後鍋裡會冒熱氣、湯面會沸騰。

**Q：灶台點著火，但是燃料沒少？**
正常。只有**鍋裡有生食材要煮**的時候才耗燃料，只有湯沒有菜是「空燒」，不耗燃料（見[灶台與火鍋](hotpot.html#fuel)）。

**Q：東西放不進鍋裡。**
鍋裡該放**食物**，熟食不能再下鍋（0.1.3 起，木頭、鐵器、礦石也徹底放不進去）。另外準星對著的那個大格滿了（9 小格）也放不進去，換一個大格試試。

**Q：想換湯底怎麼辦？**
拿**空桶右鍵鍋**，把湯舀回桶裡（鍋裡有菜的話先把菜取出來）。菌湯要用碗舀，還要求鍋裡沒有菜。

**Q：鍋裡的東西怎麼都不熟？**
- 鍋是不是「冷鍋」（不在點著的灶台或營火上）？冷鍋是不會煮熟的。
- 火力：木頭 ×0.65、煤炭 ×1.0、岩漿桶 ×1.6；湯底：高湯最慢、紅湯最快。木頭燒 + 高湯，會很慢。
- 食材本身的烹飪時間不一樣：整塊牛肉 5 秒，肥牛卷 2.5 秒（0.1.3 的吊龍約 1 秒多；見[合成配方總覽](recipes.html)的烹飪表）。

**Q：吃東西突然噁心了。**
你吃的是**冷鍋**裡的東西，有 30% 機率噁心 15 秒。喝一瓶**植物蛋白飲料**、一碗**清湯**或**醋**沾醬能解。

**Q：放高灶台提示放不下。**
高灶台要占頭頂一格，請把上面一格清空。

**Q：鍋怎麼收起來？**
灶台上的鍋：空手 **Shift + 右鍵**，整鍋連湯帶菜進背包，放下去原樣恢復（單獨擺放 / 營火上的鍋，0.1.3 起才能這樣拿）。也可以直接挖（鍋有硬度，灶台是灶台的）。

## 桌椅和餐具

**Q：凳子坐不上去。**
空手（或手裡拿的不是方塊）右鍵。兩個人之間要隔一整格；旁邊已有人坐了的話，挪一格試試。

**Q：盤子放不下 / 一格擺不下更多了。**
盤子不能重疊。小碟一格最多 5 個，長盤一格 2 個，方盤一格 1 個，混放時看占用的空間。

**Q：高桌上的東西選不到。**
本模組已經處理了：準星對著桌面上的盤子也能選取。如果真的選不到，往旁邊一點或蹲下試試。

**Q：想把桌上的盤子整個拿走。**
空手右鍵盤子，整盤（連菜）拿起來；挖也可以，只會挖對著的那一個。

## 食材

**Q：怎麼得到毛肚？**
殺牛或哞菇掉落。

**Q：怎麼得到黃豆、青蔥、香菜？**
**打矮草 / 芒草**（不要用剪刀）。青蔥、香菜各 25%，黃豆 15%。

**Q：砧板放不上東西。**
只有**能切 / 能搗**的東西能放：生牛肉、生羊肉、牛脊肉（0.1.3）、馬鈴薯、豆腐（0.1.2-alpha 這兩樣放不上，用切石機），以及能搗丸子的生豬肉、鱈魚、鮭魚。熟的不行。

**Q：為什麼飲料沒有合成配方？**
目前飲料只能在創造模式物品欄拿，或用指令 `/give`。以後可能會加做法。

## 存檔和版本

**Q：舊存檔裡的灶台、盤子、凳子沒了。**
0.1.0-alpha.1 的存檔升級後，一部分物品會遺失或變樣（當時有一次物品 ID 大改名）。0.1.1-alpha 之後，舊 ID 大部分能認回來，舊矮凳會變成長凳。**升級前一定備份存檔**，alpha 階段建議新存檔。

**Q：這個模組能和別的模組聯動嗎？**
目前留了介接方式：方塊標籤 `orients_hotpot_chronicles:heat_sources` 裡的方塊，可以當作鍋的熱源。其他聯動歡迎在 GitHub 上提建議。

**Q：1.20.1、NeoForge 版和 1.21.1 Fabric 有什麼差異？**
玩法一樣，只有熱氣粒子、吃完還碗這類很小的差別，但**新內容通常 Fabric 1.21.1 先有，其他版本晚一步**。詳見[下載、安裝與問題回報](install.html#ports)。

**Q：發現 bug 去哪裡報？**
去專案的 GitHub：<https://github.com/mryt233/Orients-Hotpot-Chronicles>，在 Issues 裡寫清楚（也可以進 **QQ 交流群 248314791**，聯絡方式見[下載、安裝與問題回報](install.html#feedback)）。請寫清楚：Minecraft 版本、模組版本、怎麼觸發、最好有螢幕截圖。
