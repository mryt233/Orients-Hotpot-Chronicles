# 常見問題

## 鍋和灶臺

**Q：鍋裡有湯，灶臺為什麼不點火？**
看三件事：① 灶膛裡有沒有燃料（右鍵磚身開啟看）；② 鍋是不是坐在灶臺上；③ 湯倒進去了沒有（沒湯的鍋不點火）。點火後鍋會冒熱氣，湯面會沸騰。

**Q：灶臺點著火，但是燃料沒少？**
正常。只有**鍋裡有生食材要煮**時才耗燃料，只有湯沒菜是「空燒」，不耗燃料（見[灶臺與火鍋](hotpot.html#fuel)）。

**Q：東西放不進鍋裡。**
鍋裡該放**食物**，熟食不能再下鍋（0.1.3-alpha-hotfix1 起木頭、鐵器、礦石也徹底放不進去）。另外對著的那大格滿了（9 小格）也放不進去，換個大格試試。

**Q：想換湯底怎麼辦？**
拿**空桶右鍵鍋**把湯舀回桶裡（有菜先取出來）。菌湯要用碗舀，而且鍋裡沒菜才行。

**Q：鍋裡的東西怎麼都不熟？**
- 鍋是不是「冷鍋」（不在點著的灶臺或營火上）？冷鍋不會煮熟。
- 火力：木頭 ×0.65、煤炭 ×1.0、巖漿桶 ×1.6；湯底：高湯最慢、紅湯最快。木頭燒 + 高湯會很慢。
- 食材烹飪時間不同：整塊牛肉 5 秒，肥牛捲 2.5 秒，吊龍約 1 秒多（見[配方大全](recipes.html)的烹飪表）。

**Q：吃東西突然反胃了。**
吃了**冷鍋**裡的東西，有 30% 機率反胃 15 秒。喝一瓶**植物蛋白飲料**、一碗**清湯**或沾**醋**能解。

**Q：放高灶臺提示放不下。**
高灶臺佔頭頂一格，把上面一格清空。

**Q：鍋怎麼收起來？**
灶臺上的鍋：空手 **Shift + 右鍵**，整鍋連湯帶菜進揹包，放下原樣恢復（單放或營火上的鍋 0.1.3-alpha-hotfix1 起也行）。直接挖也行。

## 桌椅和餐具

**Q：凳子坐不上去。**
空手（或手裡拿不是方塊的東西）右鍵。兩個人之間要隔一整格；旁邊有人就挪一格坐。

**Q：盤子放不下 / 一格擺不下更多了。**
盤子不能重疊。小碟一格最多 5 個，長盤一格 2 個，方盤一格 1 個，混放看佔的地方。

**Q：高桌上的東西點不中。**
模組已經處理了：準星對著桌面上的盤子也能選到。真點不中，往旁邊一點或蹲下試試。

**Q：想把桌上的盤子整個拿走。**
空手右鍵盤子整盤拿起來；挖也可以，只會挖對著的那一個。

## 食材

**Q：怎麼得到毛肚？**
殺牛或哞菇掉落。

**Q：怎麼得到黃豆、小蔥、香菜？**
**打矮草 / 芒草**（不要用剪刀）。小蔥、香菜各 25%，黃豆 15%。

**Q：砧板放不上東西。**
只有**能切 / 能搗**的東西能放：生牛肉、生羊肉、牛脊肉、馬鈴薯、豆腐（0.1.2-alpha 這兩樣放不上，用切石機），以及搗丸子的生豬肉、鱈魚、鮭魚。熟的不行。

**Q：為什麼飲料沒有合成配方？**
0.1.4-alpha 已經有了。柳橙飲料用柳橙、植物蛋白飲料用黃豆、之晗可樂用可可豆和蜂蜜，見[盤子、碗與飲料](tableware.html#drink)。

## 存檔和版本

**Q：舊存檔裡的灶臺、盤子、凳子沒了。**
0.1.0-alpha.1 存檔升級後部分物品會遺失或變樣（當時物品 ID 大改名）。0.1.1-alpha 後大部分能認回來，舊矮凳會變長凳。**升級前一定備份存檔**，建議新存檔玩。

**Q：這個模組能和別的模組聯動嗎？**
留了介面：方塊標籤 `orients_hotpot_chronicles:heat_sources` 裡的方塊能當鍋的熱源。其他聯動歡迎去 GitHub 提建議。

**Q：1.20.1、26.1.x、26.2 版和 1.21.1 有什麼區別？**
0.2.2-alpha 起（0.3.0-alpha 同步收口）**1.21.1（Fabric / NeoForge）、1.20.1（Fabric / Forge）、26.1.x（Fabric / NeoForge）和 26.2（Fabric / NeoForge）** 全部同步更新，玩法與內容一致。詳見[下載、安裝與回報](install.html#ports)。

**Q：發現 bug 去哪裡報？**
去 GitHub：<https://github.com/mryt233/Orients-Hotpot-Chronicles> 提 Issue（也可以進 **QQ 群 248314791**，聯絡方式見[下載、安裝與回報](install.html#feedback)）。請寫清：遊戲版本、模組版本、怎麼觸發、最好有截圖。

## 數值設定 {#config}{{since:0.2.0-alpha}}

**Q：能改食物回多少飢餓、湯底多快嗎？**
能。0.2.2-alpha 起可以直接從**模組列表**（Fabric 需裝 Mod Menu，NeoForge / Forge 原生自帶）選中本模組點「**設定**」調整並儲存；也可以直接改 `config/orients_hotpot_chronicles.json` 設定檔（裡面能調食物營養、飲料每口營養、湯底速度、燃料和沾醬等數值，每項都寫了含義、範圍和單位）。改完設定檔由管理員執行 **`/orientshotpot reload`**，不用重啟就生效；回執會報告有幾條警告。

- **多人伺服器**只改伺服器端，玩家進伺服器和重新載入時會自動同步。
- 某一項寫錯（不是數字、超出範圍、鍵名拼錯）只回退那一項並警告；整個檔案寫壞就全部用預設值，**壞檔案原樣保留**方便修。
- 配方用資料包改，再執行原版 `/reload`。
- {{since:0.3.0-alpha}}鍋專用的煮法、擀麵棍搗製也能用資料包改（配方類型 `pot_boiling`、`pounding`）；不讓下鍋的東西加進物品標籤 `orients_hotpot_chronicles:not_pot_ingredient`。<!-- mryt233 改（2026-11-11） -->
- {{since:0.3.0-alpha}}重載後，**已經下鍋的食材保留已煮的進度**，剩餘時間按新數值重算。
- {{since:0.3.0-alpha}}`cooking.items.<物品>` 只管本模組自己的食材；原版和其他模組的食材按它們自己的烹飪配方煮。
- {{since:0.3.0-alpha}}新增可調項：**圍鍋回血**（`warmth.*`）、**冷鍋反胃**（`cold_pot.*`）、**碰杯乾杯**（`cheers.*`）、**紅湯辣度**（`spicy.*`）與**戰利品掉率**（`loot.*`）；其中前四類執行 `/orientshotpot reload`（或在設定介面儲存）即生效，**修改 `loot.*` 後還須執行一次原版 `/reload`（或重啟存檔／伺服器）**才會按新機率重建戰利品池。
- 教程裡寫的數值都是預設值，伺服器改過設定以伺服器為準。

### 設定介面怎麼用 {#screen}

{{since:0.2.2-alpha}}介面分**常用**和**進階**兩張頁籤，開啟時停在**常用**：

- **常用**只放玩家最常動的幾項——最上面是**煙霧粒子強度**滑桿（另有 0% / 50% / 100% 三個快捷檔），下面是**煤炭檔灶火功率**（整體涮煮快慢的總閘）、**涮煮兜底時間**，以及**紅湯 / 清湯 / 高湯的加熱倍率**。
- **進階**把其餘全部按分類收進**可折疊分組**（涮煮時間、食材涮煮時間、湯底加熱倍率、燃料檔位、湯碗、沾醬、飲料、食物營養，{{since:0.3.0-alpha}}以及圍鍋回血、冷鍋反胃、碰杯乾杯、紅湯辣度、戰利品掉率），預設收起，點分組標題展開。
- **改數值**：每行是 `- 數值 單位 +`。點一次走一步，**按住 Shift 點一次走 10 步**；**點數值框可以直接敲數字**，敲成非數字或超出範圍會**標紅，且不讓儲存**。
- **單位**：時間按 tick 顯示（20 tick = 1 秒，夠寬時後面還會折算成秒），倍率寫「倍」，飢餓、經驗寫「點」，效果等級寫「級」，{{since:0.3.0-alpha}}半徑距離寫「格」。
- **單項恢復**：改過的那行右邊會出現 **↺**，點它只把這一項恢復成預設值；沒改的行不顯示。
- **全部恢復**：底部「恢復預設」點一次會變成「**再點一次確認**」，4 秒內再點一次才真的全部恢復（同時把粒子強度退回 100%）。
- **看說明**：滑鼠停在任意一行上，會有一句白話說明加上「範圍 x～y，預設 z」。
- 內容多時用**滾輪**或右側捲軸；**儲存並生效**才寫回設定檔並熱重載，按 ESC / 點「取消」則全部改動不保留（粒子強度會退回進界面前的值）。
- {{since:0.3.0-alpha}}**儲存失敗**：寫不進設定檔時介面停在目前頁說明原因——「改動只在本次遊戲有效」或「沒能套用改動，原設定檔已保留」；原設定檔已寫壞時，會先備份成 `orients_hotpot_chronicles.json.broken-<時間>` 再儲存，介面顯示備份名，核對後再關閉。

## 資料包 / 子模組加湯底和沾醬 {{since:0.3.0-alpha}} {#custom_soup_sauce}<!--清单#154-->

自 **0.3.0-alpha** 起，除了修改內建數值和鍋內煮法，湯底和沾醬也支援透過資料包或 Java 子模組新增與覆蓋：

- **資料包配方路徑與重載**：在資料包中放置 `data/<命名空間>/recipe/soup/<名稱>.json`（配方類型 `orients_hotpot_chronicles:soup_base`）可新增或覆蓋湯底，放置 `data/<命名空間>/recipe/seasoning/<名稱>.json`（配方類型 `orients_hotpot_chronicles:seasoning`）可新增或覆蓋沾醬；最終登記 ID 會自動剝去 `soup/` 或 `seasoning/` 目錄前綴（例如 `<命名空間>:<名稱>`）。儲存後執行 `/reload` 即可熱重載，連線時伺服器端會自動同步到用戶端（不列入原版配方書）。
- **覆蓋優先級**：資料包只需填寫要調整的部分欄位就能覆蓋內建湯底或沾醬；但玩家在 `config/orients_hotpot_chronicles.json` 或設定介面中**顯式修改過的內建數值**優先級最高，不會被資料包覆蓋（設定 > 資料包 > 程式碼預設）。第三方命名空間條目只由資料包或子模組定義，不讀寫本模組內建設定檔。
- **通用湯碗與外觀著色**：子模組可為新增湯底提供專屬碗物品與湯面貼圖（`assets/<ns>/textures/block/hot_pot_top_<path>[_boiling].png`）；沒有專屬碗物品的湯底盛出時會裝入{{i:soup_bowl}}通用湯碗 `orients_hotpot_chronicles:soup_bowl`，透過 `orients_hotpot_chronicles:soup` 資料元件記錄湯底 ID 並繼承對應效果。純 JSON 資料包無需額外貼圖，鍋面會按 `screen_colors.base`、沸騰氣泡按 `bubble_colors.body` 著色渲染清湯基底；若之後移除資料包或子模組，已有方塊和碗中的原始 ID 資料會保留，介面與湯面顯示為未知佔位。
- **子模組 Java 登記**：附屬模組可在啟動註冊凍結前呼叫 `Soups.register(...)` 與 `Seasonings.register(...)` 註冊條目，詳細欄位與格式見倉庫內的 `mod/docs/开放登记说明.md`（`mod/content/materials.json` 僅作本模組內建材質與內建湯底靜態產生器的唯一事實來源，無需修改）。
