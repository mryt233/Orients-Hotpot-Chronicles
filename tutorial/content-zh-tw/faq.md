# 常見問題

## 鍋和灶臺

**Q：鍋裡有湯，灶臺為什麼不點火？**
看三件事：① 灶膛裡有沒有燃料（右鍵磚身開啟看）；② 鍋是不是坐在灶臺上；③ 湯倒進去了沒有（沒湯的鍋不點火）。點火後鍋會冒熱氣，湯面會沸騰。

**Q：灶臺點著火，但是燃料沒少？**
正常。只有**鍋裡有生食材要煮**時才耗燃料，只有湯沒菜是「空燒」，不耗燃料（見[灶臺與火鍋](hotpot.html#fuel)）。

**Q：東西放不進鍋裡。**
鍋裡該放**食物**，熟食不能再下鍋（0.1.3-alpha-hotfix1 起木頭、鐵器、礦石也徹底放不進去）。另外對著的那大格滿了（9 小格）也放不進去，換個大格試試。

**Q：想換湯底怎麼辦？**
拿**空桶右鍵鍋**把湯舀回桶裡（有菜先取出來）。菌湯要用碗舀，而且鍋裡沒菜才行。

**Q：鍋裡的東西怎麼都不熟？**
- 鍋是不是「冷鍋」（不在點著的灶臺或營火上）？冷鍋不會煮熟。
- 火力：木頭 ×0.65、煤炭 ×1.0、岩漿桶 ×1.6；湯底：高湯最慢、紅湯最快。木頭燒 + 高湯會很慢。
- 食材烹飪時間不同：整塊牛肉 5 秒，肥牛捲 2.5 秒，吊龍約 1 秒多（見[配方大全](recipes.html)的烹飪表）。

**Q：吃東西突然噁心了。**
吃了**冷鍋**裡的東西，有 30% 機率噁心 15 秒。喝一瓶**植物蛋白飲料**、一碗**清湯**或沾**醋**能解。

**Q：放高灶臺提示放不下。**
高灶臺佔頭頂一格，把上面一格清空。

**Q：鍋怎麼收起來？**
灶臺上的鍋：空手 **Shift + 右鍵**，整鍋連湯帶菜進背包，放下原樣恢復（單放或營火上的鍋 0.1.3-alpha-hotfix1 起也行）。直接挖也行。

## 桌椅和餐具

**Q：凳子坐不上去。**
空手（或手裡拿不是方塊的東西）右鍵。兩個人之間要隔一整格；旁邊有人就挪一格坐。

**Q：盤子放不下 / 一格擺不下更多了。**
盤子不能重疊。小碟一格最多 5 個，長盤一格 2 個，方盤一格 1 個，混放看佔的地方。

**Q：高桌上的東西點不中。**
模組已經處理了：準星對著桌面上的盤子也能選到。真點不中，往旁邊一點或蹲下試試。

**Q：想把桌上的盤子整個拿走。**
空手右鍵盤子整盤拿起來；挖也可以，只會挖對著的那一個。

## 食材

**Q：怎麼得到毛肚？**
殺牛或哞菇掉落。

**Q：怎麼得到黃豆、小蔥、香菜？**
**打矮草 / 芒草**（不要用剪刀）。小蔥、香菜各 25%，黃豆 15%。

**Q：砧板放不上東西。**
只有**能切 / 能搗**的東西能放：生牛肉、生羊肉、牛脊肉、馬鈴薯、豆腐（0.1.2-alpha 這兩樣放不上，用切石機），以及搗丸子的生豬肉、鱈魚、鮭魚。熟的不行。

**Q：為什麼飲料沒有合成配方？**
0.1.4-alpha 已經有了。柳橙飲料用柳橙、植物蛋白飲料用黃豆、之晗可樂用可可豆和蜂蜜，見[盤子、碗與飲料](tableware.html#drink)。

## 存檔和版本

**Q：舊存檔裡的灶臺、盤子、凳子沒了。**
0.1.0-alpha.1 存檔升級後部分物品會遺失或變樣（當時物品 ID 大改名）。0.1.1-alpha 後大部分能認回來，舊矮凳會變長凳。**升級前一定備份存檔**，建議新存檔玩。

**Q：這個模組能和別的模組聯動嗎？**
留了介面：方塊標籤 `orients_hotpot_chronicles:heat_sources` 裡的方塊能當鍋的熱源。其他聯動歡迎去 GitHub 提建議。

**Q：1.20.1、NeoForge 版和 1.21.1 Fabric 有什麼區別？**
玩法一樣，只有熱氣粒子、吃完還碗這類很小的差別，但**新內容通常 Fabric 1.21.1 先有，其他版本晚一步**。詳見[下載、安裝與反饋](install.html#ports)。

**Q：發現 bug 去哪裡報？**
去 GitHub：<https://github.com/mryt233/Orients-Hotpot-Chronicles> 提 Issue（也可以進 **QQ 群 248314791**，聯絡方式見[下載、安裝與反饋](install.html#feedback)）。請寫清：遊戲版本、模組版本、怎麼觸發、最好有截圖。

## 數值設定 {#config}{{dev}}

:::dev
高階玩家可改遊戲目錄的 `config/orients_hotpot_chronicles.json`，再由管理員執行 **`/orientshotpot reload`**。食物飢餓值、飽和度也會立即更新，直接吃、筷子夾著吃和鍋介面裡吃用同一份數值。多人服只改伺服器端；警告條數會在命令回執裡報告。整個檔案寫壞時會用預設值，壞檔案原樣保留。這是開發中功能，**0.1.4-alpha 裡還沒有**。
:::
