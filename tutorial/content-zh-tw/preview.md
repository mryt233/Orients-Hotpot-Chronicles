# 開發版預覽

:::dev
以下是 **0.1.4-alpha 之後的開發中內容（開發版 r132，預覽版 0.2.0-alpha）**，還沒有正式釋出，正式版裡暫時沒有。名稱、數值和操作以最後釋出時為準。
:::

## 渲染修復 {#render-fix}

- 鍋點火升溫時，鍋內沸騰和氣泡不會再出現「先特別快、隨後變慢」的跳變；氣泡速度隨火力平滑變化，穩定後與正式版一致。<!--清单#87-->

## 豬肉末和火腿腸 {#sausage}

{{icons:minced_pork,raw_ham_sausage,ham_sausage,ham_sausage_slice,cooked_ham_sausage_slice}}

1. 把原版**生豬肉**放上砧板，**拿鐵菜刀右鍵切一刀**，得 **1 份豬肉末**；切石機也行。擀麵棍搗豬肉丸的做法不變。
2. **豬肉末 + 1 個原版小麥**無序合成，出 **3 根生火腿腸**。不需要額外的澱粉物品。<!--清单#72-->
3. 生火腿腸下鍋，或用熔爐、煙燻爐、營火加熱，得到**火腿腸**，預設回 **3 點飢餓**。開發中原先叫「熟火腿腸」，現在名字和 ID 都改成了「火腿腸」。<!--清单#76-->
4. **火腿腸放砧板上用菜刀切一刀**，出 **3 片火腿腸片**；切石機也能切。**生火腿腸不能放上砧板切**。腸片能直接吃，預設回 **1 點飢餓**，也能擺進碗、盤子。<!--清单#75-->
5. **火腿腸片還能再加熱一次**：下鍋、熔爐、煙燻爐、營火都行，變成**熟火腿腸片**，預設回 **2 點飢餓**。熟火腿腸片不能再下鍋。<!--清单#77-->

{{recipe:minced_pork,raw_ham_sausage,ham_sausage,ham_sausage_slice,cooked_ham_sausage_slice}}

:::tip
順序記成：**生豬肉 → 豬肉末 → 生火腿腸 → 火腿腸 → 火腿腸片 → 熟火腿腸片**。整根煮過才能切，切片以後還能再熱一次；別把開發早期的「腸片不能下鍋」當成最終玩法。
:::

## 飽了也能吃 {#chopsticks}

{{icons:bamboo_chopsticks,minecraft:bowl,quartz_small_dish}}

- 筷子夾著菜時，**飽食度滿了也能吃**：飢餓條不再漲，**飽和度照常增加**，最多加到 20。
- **本模組所有食物飽了也能直接拿著吃**（生熟食材、湯碗、毛肚、小蔥、香菜等），同樣是飢餓條不漲、飽和度照常加到 20。裝了 **Always Eat**（讓別的模組食物也能飽了吃）不衝突。<!--清单#99-->
- 夾著熟菜**直接右鍵碗、盤子還是吃**。想放回去，改成**潛行右鍵**，不再靠「吃飽了自動放回」。
- 架筷子仍是潛行右鍵碗沿、盤沿，空手右鍵拿回。**潛行右鍵有菜先放菜**（把菜放回碗盤，筷子留在手上），**空筷子潛行右鍵才架筷子**，兩項不再互搶；普通右鍵進食不變。<!--清单#74--><!--清单#84-->

## 管理員可調數值 {#config}

{{icons:hotpot_guide}}

- 遊戲會生成 `config/orients_hotpot_chronicles.json`。高階玩家可調整食物營養、湯底速度、燃料和沾醬等數值；管理員執行 **`/orientshotpot reload`** 後立即生效，不用重啟。多人服只改伺服器端，進服和重新載入時自動同步。配方用資料包改，再執行原版 `/reload`。<!--清单#78-->
- **食物的飢餓值、飽和度也支援重新載入**；直接吃、筷子夾著吃、鍋介面裡吃採用同一份營養數值。缺項或錯誤數值會分別回退預設值並警告；整個檔案寫壞時全部用預設值，**壞檔案原樣保留**方便修復。命令會報告警告條數。<!--清单#81-->

:::tip
教程裡的數值是預設值。伺服器改過設定後，以伺服器的設定為準；設定檔中的說明會寫清每項含義、範圍和單位。
:::

## 容錯和內部整理 {#maintenance}

{{icons:cutting_board,iron_kitchen_knife}}

- **砧板容錯**：整合包刪掉食材的切石機配方後，砧板仍能用內建做法切；有資料包配方時優先用資料包。<!--清单#73-->
- **子模組擴充點**：為其他子模組預留介面；不裝子模組時玩法不變。<!--清单#79-->
- **相容層整理**：第三方相容分開載入，某個相容模組出錯只跳過它自己，不影響其他模組；玩家操作不變。<!--清单#80-->
- **標籤名翻譯**：配方檢視器裡可顯示「可切食材」「需要多刀切的食材」「熱源」「可擺桌面的物品」，不用只看原始標籤 ID。<!--清单#82-->
- **相容接線修復**：第三方模組提供的湯底來源、自定義燃料會被實際烹飪邏輯識別，不再只記在相容層自己的表裡；不裝第三方模組時玩法不變。具體相容以實際安裝為準，教程不預先承諾。<!--清单#85-->
- **筷子夾菜內部修復**：NeoForge 側用筷子夾菜不再拋異常，舊存檔裡夾著菜的筷子照常讀出；這是開發工程修復，正式 NeoForge 版還沒釋出。<!--清单#86-->
- **遠距離傳送當機修復**：死亡重生或被傳送到很遠的區塊後，用戶端不會再因為舊區塊裡殘留的灶臺而當機；已經卸載的鍋不會再被用戶端繼續 tick。<!--清单#88-->
- **伺服器卡死修復**：擺了高灶台或沾醬台的伺服器，玩家進服、傳送時不會再整服卡住。<!--清单#89-->
- **灶膛燃料不再遺失**：灶上沒鍋時放進灶膛的燃料，重啟後還在；灶臺、沾醬台介面走遠或方塊被挖時會自動關上。<!--清单#90-->
- **重啟後烹飪時間正確**：重啟後鍋裡沒熟的菜按原本的時間繼續煮。<!--清单#91-->
- **鍋裡動畫更順**：點火／熄火時鍋裡輪流顯示的菜不會突然換樣，氣泡在高幀率下也平滑。<!--清单#92-->
- **營火鍋介面火力**：鍋放在營火上煮時，介面顯示正在加熱、還要幾秒，不再顯示「沒有火」。<!--清单#93-->
- **高灶台挖鍋**：站在高灶台上方對著鍋挖，只挖下鍋。<!--清单#94-->
- **漏斗接鍋**：鍋上方的漏斗只放進能煮的生食材，鍋下方的漏斗只抽走煮熟的菜。<!--清单#95-->
- **飲料營養可調**：服主可以在設定檔裡調飲料每口回多少飢餓值；重新載入命令的提示跟隨語言。<!--清单#96-->
- **內部整理**：鍋的計算和同步更省資源，玩法不變。<!--清单#97-->
- **鍋裡換菜更自然**：一格幾樣菜輪流顯示時大小不變，當前這樣沉進湯裡、下一樣浮上來。<!--清单#98-->
- **前置框架整修**：服主重新載入設定時，每條警告依自己的語言顯示並說清原因；Fabric 伺服器上用戶端和伺服器的模組版本對不上時，進服就會提示安裝相同版本，而不是進去以後功能不工作。<!--清单#100-->
- **翻譯校對**：幾種外語的火腿腸名稱更準確，zh_tw 教程用詞更自然，原版名稱對齊官方 zh_tw 譯名。<!--清单#101-->
- **載入器接線進度（開發工程）**：1.21.1 主工程已同時接通 Fabric 與 NeoForge 的開發版用戶端（鍋、灶膛、沾醬介面、火鍋指南、渲染、設定同步等）。這只是開發進度，**不代表提供了新的下載**；下載頁的正式支援矩陣仍是 0.1.4-alpha（1.21.1 Fabric）和 0.1.3-alpha-hotfix1（1.21.1 NeoForge、1.20.1）。<!--清单#83-->
