## 更多玩法數值與戰利品掉率進設定 {#r148config}

- **圍鍋回血、冷鍋反胃與碰杯乾杯可設定**：設定介面「進階」頁與 `orients_hotpot_chronicles.json` 新增「圍鍋回血」「冷鍋反胃」「碰杯乾杯」共 13 項設定（含回血範圍的「格」單位），`warmth.duration` 或 `cheers.*_duration` 設為 `0` 可關閉對應效果，改完 `/orientshotpot reload` 即時生效（詳見[數值設定](faq.html#config)）。<!--清单#156-->
- **紅湯辣度機制可設定**：設定介面「進階」頁新增「紅湯辣度」共 10 項設定，可調整每檔遞增時長、升級起點、副效果加時、抗火起始檔位／倍率、變態辣飢餓加時與嘴上冒火時長／檔位，預設值下與原機制完全一致，連線時同步用戶端提示。<!--清单#157-->
- **戰利品掉率與釣魚權重可設定（番茄拆為獨立鍵）**：設定介面「進階」頁新增「戰利品掉率」共 14 項設定（9 種打草配菜，含獨立的 `tomato` 機率，以及睡蓮蓮藕、蘑菇金針菇、殺牛牛脊肉與搶奪加成、釣魚獲蝦權重 `loot.shrimp_fishing.weight`）；改完掉率或權重後**須配合執行原版 `/reload`（或重啟）**才會按新數值重建戰利品池。<!--清单#158-->

## 開放登記與底層重構：資料包 / 子模組自訂湯底與沾醬 {#r148open}

- **0.3.0 開放登記摘要**：支援透過資料包（`recipe/soup/` 與 `recipe/seasoning/`，`/reload` 熱重載並自動同步連線用戶端，設定顯式修改優先於資料包）和 Java 子模組新增或覆蓋湯底與沾醬；沒有專屬湯碗的新增湯底可盛入{{i:soup_bowl}}通用湯碗 `soup_bowl`，純 JSON 資料包可按湯面／氣泡色著色渲染清湯基底，缺失條目保留存檔並顯示未知佔位（詳見[資料包 / 子模組加湯底和沾醬](faq.html#custom_soup_sauce)）。<!--清单#154-->
- **開放登記範例子模組與文件同步（主模組玩法不變）**：倉庫補齊可執行的雙端範例子模組與子模組依賴範圍／桌面渲染接入文件，同時補全{{i:soup_bowl}}教程圖示與檢視器沾醬臺全部 15 種內建佐料展示。<!--清单#159-->
- **內部整理（玩家無感）**：湯底與沾醬存檔改記完整 ID（如 `orients_hotpot_chronicles:clear`），相容讀取舊存檔並保留缺失擴充條目資料不覆蓋，同時升級連線同步格式（用戶端與伺服器端須同版本連線）。<!--清单#153-->
- **內部整理（玩家無感）**：桌面物件（碗、盤、飲料、瓶罐、筷架）收口為統一的 `TableItem` / `TableBlock` 開放介面與用戶端渲染回呼，方便後續擴充而無需改動核心擺放分支，玩法與外觀不變。<!--清单#155-->

## 最佳化第一批：重載、設定儲存更可靠 {#r146opt1}

- **重載後鍋裡的食材按新時間繼續煮**：改了涮煮時間再執行 `/orientshotpot reload`（或用資料包改烹飪配方再 `/reload`），已經下鍋的食材**保留已煮的進度**，剩餘時間按新數值重算，不用撈出來重下。<!--清单#142-->
- **設定儲存失敗會如實提示**：儲存時寫不進設定檔，介面會**停在目前頁**說明原因（改動只在本次遊戲有效，或沒有套用）；原設定檔如果已經寫壞，會先備份成 `orients_hotpot_chronicles.json.broken-<時間>` 再儲存，並顯示備份名。<!--清单#143-->
- **別的模組的同名食材不再套用火鍋的涮煮時間**：設定裡 `cooking.items.<物品>` 只管本模組自己的食材；原版和其他模組的食材按它們自己的烹飪配方煮。設定檔寫法不變。<!--清单#144-->
- **子模組的進食邏輯在鍋介面也生效**：拿筷子在鍋介面裡夾熟食吃，和手持筷子吃一樣會通知子模組；子模組攔下這一口時，食物留在鍋裡不扣。<!--清单#145-->
- **NeoForge 模組介紹更正**：模組清單裡不再寫「用戶端還在移植中」，問題回報入口改為專案的 Issues 頁。<!--清单#146-->
- **舊火鍋桌 ID 不再相容（只影響 Fabric 很早期的存檔）**：Fabric 版不再把最早的 `hotpot_table` 自動換成橡木火鍋桌，和 NeoForge 一致；現在的火鍋桌不受影響。<!--清单#147-->
<!-- mryt233 改（2026-11-11，r147 第三批 3E）。 -->
- **整合包可以用資料包改鍋裡的煮法和擀麵棍搗製**：鍋專用的煮法（海帶、整塊豆腐、酥肉、折耳根段）和擀麵棍搗製（肉丸、魚丸、蒜泥、蝦滑、花生碎、折耳根碎）改成了資料包配方，類型是 `orients_hotpot_chronicles:pot_boiling` 和 `orients_hotpot_chronicles:pounding`，能加、能改、能刪，執行 `/reload` 生效；往物品標籤 `orients_hotpot_chronicles:not_pot_ingredient` 裡加的東西就不能下鍋。預設玩法不變，本模組食材的涮煮時間仍以設定為準。<!--清单#148-->
- **配方檢視器的涮煮清單補全、糾正**：JEI / REI 的涮煮清單補上了原來漏掉的海帶、整根生火腿腸、火腿腸片，以及原版生肉、生魚、馬鈴薯、歌萊果這些能直接下鍋的食材；整塊豆腐煮過頭改為實際的 1 塊，酥肉再涮的經驗改為實際的 0.15 點。只是顯示改正了，實際怎麼煮沒變。<!--清单#149-->

## 飲料擺上桌的聲音、「作者推薦」成就修復 {#r146d}

- **飲料擺上桌的聲音**：滿瓶和沒喝完的飲料會同時響起瓶身落桌聲與輕輕的水晃聲；之晗可樂用更清脆的玻璃聲，空瓶只響瓶身聲。空桌面和已擺餐具的桌面都一樣。<!--清单#137-->
- **「作者推薦」成就修復**：只喝植物蛋白飲料才解鎖，瓶裝喝一口或杯裝都算；柳橙飲料、之晗可樂、水、牛奶不算。<!--清单#138-->


## 布圍裙三種花色 + 穿在身上只圍前面 {#r146b}

{{icons:cloth_apron,blue_print_cloth_apron,brown_trim_cloth_apron}}

- **布圍裙分三款**：米白粗布（預設）、**藍印花**（靛藍底 + 白色十字小花）、**棕邊帶兜**（米白底 + 深棕滾邊 + 方框口袋）。三款效果、耐久、附魔、修理材料**完全一樣**，都能防濺油、吃變態辣不冒火。
- **換款**：工作台裡**任意一款 + 染料**（無序合成）就換：白染料 → 米白、藍染料 → 藍印花、棕染料 → 棕邊。**耐久、附魔、自己改的名字全部保留**，只花一份染料。
- **穿上垂到膝蓋**：圍裙貼身，從胸口垂到膝蓋上面，走路時下襬跟著腿往前擺、坐下平鋪在腿上；袖子和後背透明，背後只有一圈掛脖帶，不再像一件毛衣。<!--清单#141-->

## 鐵菜刀朝向固定、設定介面重做、芝麻醬蠔油能擺上桌 {#r146a}

{{icons:iron_kitchen_knife,sesame_paste,oyster_sauce}}

- **鐵菜刀朝向不再靠模型翻轉**：刀柄↙、刀尖↗、鋒刃↘ 的樣子直接畫進貼圖，物品欄、拿在手裡、火鍋指南、網頁教程和查看器四處**完全一致**，以後誰重跑貼圖產生腳本都不會再翻回去。注意：拿在手裡時刀刃會換到另一側，和物品欄裡看到的一樣，這是預期效果。<!--清单#133-->
- **設定介面分「常用 / 進階」**：從模組清單點「設定」進入後，預設是**常用**頁——煙霧粒子強度，加上最常動的幾項（煤炭檔灶火功率、涮煮兜底時間、紅湯 / 清湯 / 高湯的加熱倍率）。其餘全部收進**進階**頁，按涮煮時間、食材、湯底、燃料、湯碗、沾醬、飲料、食物營養分成可折疊的分組，預設收起。每行 `- 數值 單位 +`，按住 **Shift** 點一次走 10 步，點數值框可以直接鍵入數字（輸錯標紅、不讓儲存）；改過的那行右邊出現 **↺**，點它只恢復這一項；底部「恢復預設」點一次變「再點一次確認」，再點才全部恢復；滑鼠停在任意一行上會有一句白話說明和範圍 / 預設值。<!--清单#134-->
- **芝麻醬、蠔油能擺上桌（只是擺設）**：手持它們**潛行 + 右鍵**火鍋桌 / 高火鍋桌頂面的空位就放下（和竹筷、沾醬碗一樣佔一個盤子格），桌上會顯示成對應的小立體瓶子（芝麻醬是帶白標籤的矮玻璃罐、蠔油是細高的深色瓶子）；**空手右鍵**拿回來，對著瓶子挖也只挖這一瓶。擺在桌上的瓶子**不能沾醬、不能加料**——想給菜加上這一味，仍然去沾醬臺打沾醬。<!--清单#135-->
