# 桌子、備菜架與凳子

火鍋得圍著桌子吃。模組裡有**矮火鍋桌**（{{i:hotpot_table}}，貼近地面）與**高火鍋桌**（{{i:tall_hotpot_table}}，1.5 格高）、**三種備菜架**（落地架、桌面架、掛架），以及配套的**兩套木頭凳子**（11 種木頭）：

{{icons:hotpot_table,tall_hotpot_table,multi_tier_prep_rack,desktop_prep_rack,hanging_prep_rack}}

- **40 張舊桌子收束為 2 張通用桌**{{since:0.3.1-alpha}}：早期的 11 種木頭矮桌、11 種木頭高桌和 18 張石料 / 金屬桌，現已統一收束為 **{{i:hotpot_table}}** 與 **{{i:tall_hotpot_table}}**，合成配方改用任意原版木板（`#minecraft:planks`），外觀透過**換材質**自由搭配。
- **全火鍋桌統一不可燃**：木質外觀的火鍋桌也不會被火焰燒毀。
<!--guide-collapse-->
- **舊存檔平滑無損遷移**：更新存檔後，**已擺放的舊桌方塊**（區塊載入時）、**背包裡的舊桌物品**（進服時）都會自動平滑遷移並保留原本外觀；**箱內舊桌**會原樣保留，取出放置時原地無損升級（進背包後重進存檔也會自動轉換），不會丟檔或變紫黑方塊。
<!--/guide-collapse-->

## 矮火鍋桌

{{img:hotpot-low-table.webp|矮火鍋桌 + 灶台 + 板凳}}

{{recipe:hotpot_table}}

- 桌面和**矮灶台的磚面齊平**，灶台能直接嵌在桌子中間，像一張整桌。
- 桌面下面像倒放的樓梯，朝外側往裡收 4 像素，給膝蓋留位置。
- **會自己連**：哪邊挨著另一張桌子（矮桌、高桌都行）或灶台就自己鋪滿，連成長桌；圍成方圈或擺出拐角時，轉角內側的磚腳和桌沿也會嚴絲合縫合攏，不露空洞。
- **統一不可燃**；挖掘速度、破壞粒子與敲擊音效跟隨目前部位材質，**固定硬度 2.0，空手也可拆下**。

## 高火鍋桌

{{img:hotpot-tall-table.webp|高火鍋桌 + 高灶台 + 條凳}}

{{icons:tall_hotpot_table}}

{{recipe:tall_hotpot_table}}

- **1.5 格高**，桌面懸出一圈，下面是桌腿，朝外也收進 4 像素留腿部空間。
- 下面一格是**紅磚塊**，上面是木板（配方裡用 3 個紅磚塊與 3 塊任意木板合成）。
- 和**高灶台**搭配：灶台火口正對桌子時，桌子那側會**去掉磚身只留木頭**，方便看火。
- 同樣會自己連，和矮桌、灶台都能連，且**統一不可燃**（固定硬度 2.0，空手可拆）。
- 方塊比一格高，**準星對著桌面上的東西也能選得中**（盤子、碗放在高桌上不會點不到）。

### 桌上擺東西 {#decor}

- **盤子、碗、飲料、沾醬碗**都放桌面上，見[盤子、碗與飲料](tableware.html)。
- **小擺件**（燈籠、花盆、蠟燭、蛋糕以及{{i:desktop_prep_rack}}等 `table_decorations` 標籤內的方塊）放火鍋桌上會**貼住桌面**，不再浮空。
- 其他普通方塊：矮桌上浮空 5 像素，高桌上嵌進 7 像素，當裝飾也不錯。

## 桌面與底座換材質 {#swap_materials}{{since:0.3.1-alpha}}

{{icons:minecraft:oak_planks,minecraft:bricks,minecraft:quartz_block,minecraft:smooth_stone}}

做好通用**火鍋桌**與**高火鍋桌**後，無需再依材料分別合成，對著桌子就能直接更換**桌面**和**底座**的材質（**支援其他模組的實心方塊**）：

1. **分部位更換（1 進 1 出無損退還）**：手持任意實心方塊（完整不透明、非發光、無方塊實體且不在黑名單內的方塊），**不潛行直接右鍵**火鍋桌：
   - 對著**上半部分**（矮桌桌面及以上 / 高桌桌面及以上）右鍵，替換**桌面**材質；
   - 對著**下半部分**（桌身 / 底座）右鍵，替換**底座**材質（高桌連同中圈與底牆整段更換）；
   - 每次消耗 1 個手持方塊；若該部位原本已經替換過材質，會把舊材質方塊**1 進 1 出無損退還**（預設內建的木板 / 紅磚底色不退還）。
2. **潛行操作區分**：
   - **潛行 + 空手右鍵**對應部位：將已換上的材質方塊**無損拆出**並恢復預設外觀；
   - **潛行 + 手持方塊右鍵**：豁免換材質判斷，按原版方式正常貼桌邊搭方塊建造。
3. **挖掘手感與保存**：換材質後，桌子的**挖掘速度、破壞粒子與音效跟隨目前部位材質**——持續挖掘時指著桌面會濺出桌面材質碎屑，指著底座會濺出底座材質碎屑——且**固定硬度 2.0、空手也可拆**；挖掉掉落或滑鼠中鍵複製都會完整保留已換材質。
<!--guide-collapse-->
4. **舊存檔預設說明**：從早期版本 40 張預設桌遷移而來的桌面 / 底座外觀會保留，但**不能透過潛行空手拆出方塊**（防止刷物），想改外觀時**直接手持任意新方塊覆蓋右鍵**即可。
<!--/guide-collapse-->
5. **換材質範圍設定**：可在設定介面「桌架換材質」或設定檔調整 `table_materials.mode`：
   - `any_solid`（預設）：允許任意符合條件的實心不透明非容器方塊（受白名單 `table_materials_allow` 與黑名單 `table_materials_deny` 標籤控制）；
   - `tag_only`：只允許白名單標籤內的方塊；
   - `off`：關閉換材質功能。

## 石料和金屬火鍋桌 {#stone}{{since:0.1.4-alpha}}

{{icons:minecraft:smooth_stone,minecraft:polished_granite,minecraft:polished_deepslate,minecraft:quartz_block,minecraft:cut_copper}}

0.1.4-alpha 起導入的平滑石頭、磨製安山岩 / 閃長岩 / 花崗岩 / 深板岩 / 黑石、石英、切製銅、鐵共 **9 種**石料與金屬桌面（原 18 張預設桌），自 **0.3.1-alpha** 起已全面併入通用火鍋桌的**分部位換材質**系統：做出{{i:hotpot_table}}或{{i:tall_hotpot_table}}後手持對應石料或金屬方塊右鍵桌面即可換裝，舊存檔裡原有的石料和金屬火鍋桌會在載入時自動無損遷移並保留原有外觀。

## 三種備菜架 {#prep_racks}{{since:0.3.1-alpha}}

{{icons:multi_tier_prep_rack,desktop_prep_rack,hanging_prep_rack}}

備菜架用來收納盤子、食材、布圍裙和順手廚具，全部支援**無介面準星分格直接放取**（拿對應物品右鍵放到準星那格，已有物則順延到最近空位；空手右鍵拿回；挖掉會掉出全部已放物品），在開啟開關時也同樣支援**手持實心方塊右鍵整體換材質**（潛行空手拆出，受 `mode.rack_swap_materials` 與 `table_materials.mode` 控制）：

- **{{i:multi_tier_prep_rack}}（6 格落地架）**：3 層鐵木結構，每層 2 格共 **6 格**。可擺放盤子與碗（`#rack_plates` 及桌面物件）以及可直接食用或下鍋的食材。
- **{{i:desktop_prep_rack}}（4 格桌面備菜架）**：雙層階梯桌面架（前下 2 格 + 後上 2 格，共 **4 格**）。已加入 `table_decorations` 標籤，放在矮火鍋桌或高火鍋桌上會自動**貼面抬高 / 下沉**緊貼桌面，適合直接擺在桌邊備菜。
- **{{i:hanging_prep_rack}}（4 格雙態掛架）**：共 **4 格**掛鉤，放置時根據點擊位置自動切換狀態——對著牆面側面放成 **`wall`（靠牆）**，對著天花板底面放成 **`ceiling`（吸頂）**。專門用於懸掛 `#rack_hangables` 廚具（鐵菜刀、擀麵棍、竹筷、木壓板、剪刀、桶）以及**全部 3 款布圍裙**（{{i:cloth_apron}}、{{i:blue_print_cloth_apron}}、{{i:brown_trim_cloth_apron}}）。

## 板凳和條凳

| 凳子 | 高度 | 配方一次出 |
| --- | --- | --- |
| {{i:oak_stool}} | 矮，坐高約 7/16 格 | 3 個 |
| {{i:oak_bench}} | 一格高，凳面和桌面齊平；坐高 1.25 格 | 3 個 |

{{recipe:oak_stool,oak_bench}}

兩種凳子都有 11 種木頭，配方只是換對應木板。

### 擺放

- **朝向**：放的時候面朝哪邊，凳子（和坐上去的人）就面朝哪邊。
- **連成長凳**：同一直線上挨著的兩個凳子（高矮一樣）會**自己連成長凳**，中間腿去掉、兩頭腿往裡收，垂直放的不連。**一條最長連 3 格**，再往旁邊放就不連了，不管站哪邊放都會連。
- 條凳腿是斜著的「A」字腿，由程式碼畫出來；碰撞與選中範圍和凳面同寬，貼著條凳走動不會卡腳。

### 條凳搭起來能當梯子 {#climb}{{since:0.2.2-alpha}}

一條條凳就是一格高，疊起來正好是一級級臺階。

1. **手拿條凳（不潛行）右鍵已經放好的條凳**，它會自動順著這一摞往上找，直接疊到**最頂上**，一次消耗 1 條。
   - 也可以直接對著凳子的**頂面**放，效果一樣。
   - 最多疊 **16 層**，再高就放不上了。
2. 疊到 **2 層以上**，這一摞就成了**梯子**：貼著凳子**任意一面**往前走或按跳躍，就能像爬梯子一樣一級級上下。單擺一張不會觸發，免得圍著桌子走動時不小心爬上去。
3. **頂層照樣能坐**：空手右鍵最上面那張，坐姿和普通條凳一樣。中間層（頭頂還壓著凳子）坐不了。
4. 坐著的時候別人往你頭頂疊凳子，你會自動起身，把位置讓出來。
5. 拆凳子照常挖，坐在上面的人會被放下。

{{icons:oak_bench,bamboo_bench}}

:::tip
疊條凳順手，拆也順手：想夠高處的東西、想在火鍋桌邊搭個「上舖」，幾條凳子就夠。把條凳往條凳上疊、或者順著凳塔往上爬，都會解鎖成就「**步步高升**」。
:::

### 怎麼坐 {#sit}

1. **空手**（或手裡拿不是方塊的東西）**右鍵凳子**就坐上去了。
2. 點凳子**中間**坐中間；點**兩格交界處**坐兩格中間。
3. 兩個人之間**至少隔一整格**，不會擠在一起。
4. **Shift（潛行）**起身，站到凳子後面。

:::tip
搭配推薦：「**條凳 + 高桌 + 高灶台**」是一套，「**板凳 + 矮桌 + 矮灶台**」是一套，別混著搭，高度才對得上。
:::
