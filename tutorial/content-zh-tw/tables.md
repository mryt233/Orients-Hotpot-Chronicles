# 桌子與凳子

火鍋得圍著桌子吃。模組裡有**兩套桌凳**：矮的一套（貼近地面，像家裡火鍋桌）和高的一套（1.5 格高，像店裡的高腳桌），每套都有 **11 種木頭**：

{{icons:oak_hotpot_table,spruce_hotpot_table,birch_hotpot_table,jungle_hotpot_table,acacia_hotpot_table,dark_oak_hotpot_table,mangrove_hotpot_table,cherry_hotpot_table,bamboo_hotpot_table,crimson_hotpot_table,warped_hotpot_table}}

橡木、杉木、樺木、叢林木、相思木、黑橡木、紅樹林木、櫻花木、竹、緋紅蕈木、扭曲蕈木——桌子**貼圖用的就是原版木板**，配方也只是換成對應的木板。

## 矮火鍋桌

{{img:hotpot-low-table.webp|矮火鍋桌 + 灶臺 + 矮凳}}

{{recipe:oak_hotpot_table}}

- 桌面和**矮灶臺的磚面齊平**，灶臺能直接嵌在桌子中間，像一張整桌。
- 桌面下面像倒放的樓梯，朝外一側往裡收 4 像素，給膝蓋留位置。
- **會自己連**：哪邊挨著另一張桌子（矮桌、高桌都行）或灶臺就自己鋪滿，連成長桌。
- 木頭桌子會著火，能用斧頭快速挖。

## 高火鍋桌

{{img:hotpot-tall-table.webp|高火鍋桌 + 高灶臺 + 長凳}}

{{icons:oak_tall_hotpot_table}}

{{recipe:oak_tall_hotpot_table}}

- **1.5 格高**，桌面懸出一圈，下面是桌腿，朝外也收進 4 像素留腿部空間。
- 下面一格是**磚塊**，上面是木板（配方裡有 3 個磚塊）。
- 和**高灶臺**搭配：灶臺火口正對桌子時，桌子那側會**去掉磚身只留木頭**，方便看火。
- 同樣會自己連，和矮桌、灶臺都能連。
- 方塊比一格高，**準星對著桌面上的東西也能選得中**（盤子、碗放在高桌上不會點不到）。

### 桌上擺東西 {#decor}

- **盤子、碗、飲料、沾醬碗**都放桌面上，見[盤子、碗與飲料](tableware.html)。
- **小擺件**（燈籠、花盆、蠟燭、蛋糕等）放火鍋桌上會**貼住桌面**，不再浮空。
- 其他普通方塊：矮桌上浮空 5 像素，高桌上嵌進 7 像素，當裝飾也不錯。

兩種凳子都有 11 種木頭，配方只是換對應木板。

### 擺放

- **朝向**：放的時候面朝哪邊，凳子（和坐上去的人）就面朝哪邊。
- **連成長凳**：同一直線上挨著的兩個凳子（高矮一樣）會**自己連成長凳**，中間腿去掉、兩頭腿往裡收，垂直放的不連。**一條最長連 3 格**，再往旁邊放就不連了。0.1.2-alpha 裡放的時候朝向一樣才連；0.1.3-alpha-hotfix1 起不管站哪邊放都會連。
- 長凳腿是斜著的「A」字腿，由程式碼畫出來。

### 怎麼坐 {#sit}

1. **空手**（或手裡拿不是方塊的東西）**右鍵凳子**就坐上去了。
2. 點凳子**中間**坐中間；點**兩格交界處**坐兩格中間。
3. 兩個人之間**至少隔一整格**，不會擠在一起。
4. **Shift（潛行）**起身，站到凳子後面。

:::tip
搭配推薦：「**長凳 + 高桌 + 高灶臺**」是一套，「**矮凳 + 矮桌 + 矮灶臺**」是一套，別混著搭，高度才對得上。
:::
