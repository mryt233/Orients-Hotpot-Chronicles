# 桌子與凳子

火鍋得圍著桌子吃。模組裡有**兩套桌椅**：矮的一套（貼近地面、像家裡的火鍋桌）和高的一套（1.5 格高、像火鍋店的高腳桌），每套都有 **11 種木頭**的版本：

{{icons:oak_hotpot_table,spruce_hotpot_table,birch_hotpot_table,jungle_hotpot_table,acacia_hotpot_table,dark_oak_hotpot_table,mangrove_hotpot_table,cherry_hotpot_table,bamboo_hotpot_table,crimson_hotpot_table,warped_hotpot_table}}

桌子使用**原版木材的材質**，更換木材種類即可製作對應版本。原版繁中名稱與模組桌椅名稱有幾處不同，找材料時請對照：

| 原版材料的木材種類 | 模組桌椅名稱使用的木材種類 |
| --- | --- |
| 橡木、叢林木、櫻花木、竹 | 橡木、叢林木、櫻花木、竹 |
| 杉木 | 雲杉木 |
| 樺木 | 白樺木 |
| 相思木 | 金合歡木 |
| 黑橡木 | 深色橡木 |
| 紅樹林木 | 紅樹木 |
| 緋紅蕈木 | 緋紅木 |
| 扭曲蕈木 | 詭異木 |

本指南提到的「木板」，是指原版繁中物品名稱中的「木材」，例如橡木材、杉木材；不要拿原木代替。

## 矮火鍋桌

{{img:hotpot-low-table.webp|矮火鍋桌 + 灶台 + 矮凳}}

{{recipe:oak_hotpot_table}}

- 桌面和**矮灶台的磚面齊平**，所以灶台可以直接嵌在一排桌子中間，形成連續的桌面。
- 桌面下面像倒放的樓梯，朝外一側往裡收 4 像素，給膝蓋留出位置。
- **會自己連**：東南西北哪邊挨著另一張桌子（矮桌、高桌都行）或灶台，那一側就鋪滿，一排排連成長桌。
- 木頭的桌子會著火，也能用斧頭快速挖。

## 高火鍋桌

{{img:hotpot-tall-table.webp|高火鍋桌 + 高灶台 + 長凳}}

{{icons:oak_tall_hotpot_table}}

{{recipe:oak_tall_hotpot_table}}

- **1.5 格高**，桌面板懸出一圈，下面 0..19 像素是桌腿，朝外也收進 4 像素。
- 下面一格高是**原版磚塊**，上面是木板（所以配方裡有 3 個磚塊）。
- 和**高灶台**搭配：灶台火口正對著桌子時，桌子在那一側會**去掉磚身只留木頭部分**，這樣你能看到灶膛裡的火。
- 同樣會自己連，和矮桌、灶台都能連。
- 方塊比一格高，所以**準星對著桌面上的東西也能選得到**（盤子、碗放在高桌上不會點不到）。

### 桌上擺東西 {#decor}

- **盤子、碗、飲料、沾醬碗**都放在桌面上，見[盤子、碗與飲料](tableware.html)。
- **小型擺飾**（燈籠、花盆、蠟燭、蛋糕等）放在火鍋桌上，會**貼住桌面**，不再浮空。
- 其他一般方塊：矮桌上會浮空 5 像素，高桌上會嵌進去 7 像素——按原版方塊擺，當裝飾也不錯。

## 矮凳和長凳

本指南用「矮凳」與「長凳」區分高度；遊戲內物品名稱分別為「板凳」與「條凳」，請搭配下方圖示辨識。

| 凳子 | 高度 | 配方一次出 |
| --- | --- | --- |
| {{i:oak_stool}}（矮凳） | 矮，坐高約 7/16 格 | 3 個 |
| {{i:oak_bench}}（長凳） | 一格高，凳面和桌面齊平；坐的位置抬到 1.25 格 | 3 個 |

{{recipe:oak_stool,oak_bench}}

兩種凳子都有 11 種木頭，配方只是木板換成對應的木板。

### 擺放

- **朝向**：放的時候你面朝哪邊，凳子（和坐上去的人）就面朝哪邊。
- **連成長凳**：同一條線上挨著的兩個凳子（高矮一樣，木頭可以不同）會**自己連成長凳**，中間的腿去掉、兩頭的腿往裡收，垂直擺的不會連。0.1.2-alpha 裡要**放的時候朝向一樣**才連（人站在另一邊放就連不上，會錯開）；0.1.3 起不管站哪邊，同一條線都會連。
- 長凳的腿是斜著的「A」字腿，由程式碼畫出來（原版模型轉不了這麼小的角度）。

### 怎麼坐 {#sit}

1. **空手**（或手裡拿著不是方塊的東西）**右鍵凳子**，就坐上去了。
2. 點凳子**格子的中間**坐中間；點**兩格交界處**坐兩格中間。
3. 兩個人之間**至少隔一整格**，不會擠在一起。
4. **Shift（潛行）**起身，站到凳子的後面。

:::tip
想坐得舒服、吃得順手：「**長凳 + 高桌 + 高灶台**」是一套，「**矮凳 + 矮桌 + 矮灶台**」是一套，別混著搭，高度才對得上。
:::
