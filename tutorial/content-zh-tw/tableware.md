# 盤子、碗與飲料

火鍋桌上要擺滿：盤子裝生菜，碗盛湯，飲料解辣，筷子夾菜。

## 盤子 {#plate}

### 盤子的種類

**5 種材質 × 6 種大小 = 30 種盤子**：

| 材質 | 做小碟用的原料 |
| --- | --- |
| 石英 | {{i:minecraft:quartz}} |
| 竹編 | {{i:minecraft:bamboo}} |
| 紅陶 | {{i:minecraft:brick}} |
| 銅 | {{i:minecraft:copper_ingot}} |
| 鐵 | {{i:minecraft:iron_ingot}} |

| 大小 | 樣子 | 能裝幾樣菜 |
| --- | --- | --- |
| 小碟（1×1） | 一格 | 3 樣 |
| 雙格盤（1×2） | 兩格長 | 6 樣 |
| 三格長盤（1×3） | 三格長 | 9 樣 |
| 四格方盤（2×2） | 方的 | 12 樣 |
| 五格長盤（1×5） | 五格長 | 15 樣 |
| 八格大盤（2×4） | 大的 | 24 樣 |

每一**格**最多裝 3 樣菜（任何菜都行），盤子容量 = 格數 × 3。

### 擺放 {#place}

- 拿盤子**右鍵桌面或地面**就擺上去了。
- 一格空間裡可以**擺好幾個**，不能重疊，不同樣能混著放：小碟一格 5 個、長盤一格 2 個、方盤一格 1 個。
- 盤子會自動貼桌面：矮桌上下移 5 像素，高桌上上移 7 像素。

### 往盤子裡放菜和拿菜 {#use}

操作都對**準星對著的那一個盤子**生效：

| 你手裡拿著 | 右鍵盤子 |
| --- | --- |
| 盤子 | 再擺一個盤子 |
| 食物 | 放一樣菜進盤子（一格最多 3 樣） |
| 竹筷 | 夾走**最後放的**菜；竹筷夾著熟菜時右鍵盤子 = **吃掉**，吃飽了吃不下才放回 |
| 空手 | **把盤子（連菜）拿起來** |
| 空手 + 潛行 | 取出最後放的一樣菜到背包（盤子留著） |

- **挖盤子**：只挖對著的那個，菜會一起掉出來。
- **滑鼠中鍵**：複製準星對著的盤子，**連菜一起**。
- 裝了菜的盤子，物品欄圖示和拿在手裡都會畫出裡面的菜；提示像收納袋，同樣的菜合併寫「×數量」。
- **端著菜下鍋**：拿裝了菜的盤子右鍵鍋，裡面的**生食材**倒進鍋，熟的留在盤裡。

## 碗和湯碗 {#bowl}

### 碗的新用法

普通的**碗**（{{i:minecraft:bowl}}）也能上桌：

- **擺在桌上**：和盤子一樣擺，一隻碗能裝 **3 樣菜**，當小盤子用。
- **拿碗右鍵鍋**：先盛**熟菜**（最多 3 樣）；鍋裡沒熟菜就盛**湯**（湯盛不完，鍋裡的湯不會少）。
- 裝了菜的碗右鍵鍋，整碗倒進鍋裡。

### 六種湯碗

盛出來的湯是單獨的**湯碗**，喝了都回 **4 點飢餓**，還各帶效果：

| 湯碗 | 效果 |
| --- | --- |
| {{i:clear_broth_bowl}} | 解除噁心 |
| {{i:rich_stock_bowl}} | 飽和度高，更抗餓 |
| {{i:mushroom_broth_bowl}} | 生命恢復 I，6 秒 |
| {{i:spicy_red_broth_bowl}} | 力量 I，9 秒；但會飢餓 3 秒 |
| {{i:tomato_soup_bowl}} | 生命恢復 I，6 秒；解噁心 |
| {{i:three_fresh_soup_bowl}} | 水下呼吸 15 秒 |

喝完變回空碗，也能擺在桌上。

:::tip
換湯底時**用空桶舀**，一律用桶。菌湯用碗舀成湯碗是另一回事。
:::

## 飲料 {#drink}

{{icons:orange_drink,plant_protein_drink,orient_cola,glass_cup}}

| 飲料 | 每一口的效果 |
| --- | --- |
| {{i:orange_drink}} | 回 2 點飢餓；速度 15 秒；**解辣**（清掉飢餓效果） |
| {{i:plant_protein_drink}} | 回 2 點飢餓；**解辣**，解除噁心 |
| {{i:orient_cola}} | 回 2 點飢餓；速度、急迫各 15 秒；瓶子會冒氣泡 |

- 一瓶喝 **4 口**，飽了也能喝，喝完留下**空瓶**，空瓶也能擺桌上。
- 飲料能**擺在桌上**右鍵喝；提示會寫「還剩幾口」。
- 三種飲料都有配方了：柳橙飲料用柳橙，植物蛋白飲料用黃豆，之晗可樂用可可豆和蜂蜜。**柳橙**從橡木、黑橡木樹葉掉。

### 玻璃杯 {#cup}

{{recipe:glass_cup}}

- 拿飲料右鍵空杯倒一杯（{{i:orange_drink_cup}}{{i:plant_protein_drink_cup}}{{i:orient_cola_cup}}），**一杯一口**，喝完變回空杯，能擺桌上。
- 瓶子喝完留下**空瓶**（{{i:empty_orange_drink_bottle}}{{i:empty_plant_protein_drink_bottle}}），空瓶能擺桌上，也能拿去舀鍋釜裡的飲料。
- **一杯水、一杯牛奶**（{{i:water_cup}}{{i:milk_cup}}）：拿水桶 / 奶桶右鍵空杯，**桶不會空**；空杯對著水源右鍵也能舀水。喝水沒效果，牛奶清掉所有效果，都不回飢餓。

### 飲料倒進鍋釜 {#cauldron}

- 拿飲料瓶或滿杯右鍵原版**鍋釜**，飲料倒進去：一鍋只裝一種，最多 **12 口**（3 滿瓶），每 4 口水面高一檔，水換成飲料的顏色，可樂鍋會冒氣泡。
- **空杯舀一口**；原版玻璃瓶或這種飲料的空瓶舀**一瓶**（最多 4 口）。舀空變回空鍋釜，倒別的飲料會提示「裝的是別的飲料」。

## 筷子 {#chopsticks}

{{recipe:bamboo_chopsticks}}

- **開鍋介面**：拿竹筷 **Shift + 右鍵鍋**。
- **從鍋裡夾熟食**：**直接右鍵鍋**夾起準星那格的一樣熟食（沒熟食會提示）。
- **從碗、盤子裡夾菜**：右鍵碗或盤子夾走最後放的那樣菜。
- **放進鍋裡**：夾著**生食材**右鍵鍋下鍋。
- **吃**：夾著熟菜**按住右鍵**吃掉（吃飽了吃不下，右鍵碗或盤子放回去）。沾過料效果也算上。
- **沾醬**：夾著菜右鍵桌上的沾醬碗沾一口，見[沾醬](sauce.html)。
- **架在碗沿、盤沿上**：拿竹筷（夾著菜也行）**Shift + 右鍵**桌上的碗或盤子，筷子就橫躺在碗口上，夾著的菜在正中間；**空手右鍵**把筷子拿回來（菜還在）。挖掉碗時筷子一起掉。
