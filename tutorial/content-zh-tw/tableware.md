# 盤子、碗與飲料

準備一桌火鍋：盤子裝未煮熟的食材、碗用來盛湯，再搭配飲料與夾菜用的筷子。

## 盤子 {#plate}

### 種類

**5 種材質 × 6 種大小 = 30 種盤子**：

| 材質 | 做小碟用的原料 |
| --- | --- |
| 石英 | {{i:minecraft:quartz}} |
| 竹編 | {{i:minecraft:bamboo}} |
| 紅陶 | {{i:minecraft:brick}} |
| 銅 | {{i:minecraft:copper_ingot}} |
| 鐵 | {{i:minecraft:iron_ingot}} |

| 大小 | 樣子 | 能裝幾份食材 |
| --- | --- | --- |
| 小碟（1×1） | 一格 | 3 份 |
| 雙格盤（1×2） | 兩格長 | 6 份 |
| 三格長盤（1×3） | 三格長 | 9 份 |
| 四格方盤（2×2） | 方的 | 12 份 |
| 五格長盤（1×5） | 五格長 | 15 份 |
| 八格大盤（2×4） | 大的 | 24 份 |

每一**格**最多裝 3 份食材（小碟也是 3 份），所以盤子容量 = 格數 × 3。

### 擺放 {#place}

- 拿著盤子**右鍵桌面或地面**，盤子就擺在那上面。
- 一格空間裡可以**擺好幾個**，不能重疊，不同樣的可以混著放：小碟一格 5 個、長盤一格 2 個、方盤一格 1 個。
- 盤子會自動貼著桌面：在矮桌上下移 5 像素，在高桌上上移 7 像素。

### 往盤子裡放菜、拿菜 {#use}

下面的操作都只作用於**準星對著的那一個盤子**：

| 你手裡拿著 | 右鍵盤子 |
| --- | --- |
| 盤子 | 再擺一個盤子 |
| 食物 | 放一份食材進盤子（一格最多 3 份） |
| 筷子 | 夾走**最後放的**那份食材；筷子夾著菜時右鍵 = 放回去 |
| 空手 | **把這個盤子（連菜）拿起來** |
| 空手 + 潛行 | 取出最後放的一份食材到背包（盤子留著） |

- **挖盤子**：只挖對著的那一個，盤裡的菜會一起掉出來。
- **滑鼠中鍵**：複製準星對著的那個盤子，**連菜一起**。
- 裝了菜的盤子，**物品欄圖示、手裡拿著時**都會畫出裡面的菜；提示像原版束口袋，同樣的菜合併寫「×數量」。
- **端著食材下鍋**：拿著裝了菜的盤子右鍵鍋，盤裡**生的**食材倒進鍋裡，熟的留在盤子裡。

## 碗和湯碗 {#bowl}

### 原版碗也能用

**原版的碗**（{{i:minecraft:bowl}}）也被加了新用法：

- **擺在桌上**：和盤子一樣的放法，一個碗能裝 **3 份食材**，當小盤子用。
- **用碗右鍵鍋**：先盛**熟菜**（最多 3 份）；鍋裡沒有熟菜，就盛一碗**湯**（湯盛不完，鍋裡的湯不會減少）。
- 已經裝了菜的碗右鍵鍋，整碗倒進鍋裡。

### 四種湯碗

盛出來的湯是模組自己的**湯碗**物品，喝下去都恢復 **4 點飢餓值**，還各帶效果：

| 湯碗 | 效果 |
| --- | --- |
| {{i:clear_broth_bowl}} | 解除噁心（把冷鍋吃壞的肚子調理好） |
| {{i:rich_stock_bowl}} | 飽食度高，更耐餓 |
| {{i:mushroom_broth_bowl}} | 回復 I，6 秒 |
| {{i:spicy_red_broth_bowl}} | 力量 I，9 秒；但會飢餓 3 秒（辣的） |

湯碗吃完變回原版的空碗，也能擺在桌上。

:::tip
倒掉鍋裡的湯（想換湯底）：**用空桶舀**，一律用桶，不管是什麼湯。菌湯用碗舀成湯碗是另一回事。
:::

## 飲料 {#drink}

涮火鍋怎麼能沒有飲料？

下方的「橙子飲料」沿用遊戲內物品名稱，也就是柳橙飲料。「植物蛋白飲料」則保留原名，不另稱豆漿，以免混淆飲品種類。

{{icons:orange_drink,plant_protein_drink,empty_orange_drink_bottle,empty_plant_protein_drink_bottle}}

| 飲料 | 每一口的效果 |
| --- | --- |
| {{i:orange_drink}} | 恢復 2 點飢餓值；加速 15 秒；**解辣**（清掉飢餓效果） |
| {{i:plant_protein_drink}} | 恢復 2 點飢餓值；**解辣**，並解除噁心 |

- 一瓶可以喝 **4 口**，吃飽了也能喝（不受飢餓值限制），喝完留下**空瓶**，空瓶也能擺在桌上。
- 飲料能**擺在桌上**，右鍵喝；提示會寫「還剩幾口」。
- 目前飲料**沒有合成配方**，在創造模式物品欄（「食物」標籤）裡取，或用指令 `/give`。

## 筷子 {#chopsticks}

{{recipe:bamboo_chopsticks}}

筷子是這個模組裡最常用的工具：

- **開鍋介面**：拿著筷子右鍵鍋。
- **夾菜**：對著盤子右鍵，夾走最後放的那份食材（夾著時，筷子尖上會看到那份食材）。
- **放進鍋裡**：夾著菜右鍵鍋，放進你點的那個大格。
- **吃**：夾著能吃的菜，對著空氣**按住右鍵**，就吃掉（沾過料的話，效果也會算上）。
- **沾醬**：夾著菜點一下桌上的沾醬碗，見[沾醬](sauce.html)。
