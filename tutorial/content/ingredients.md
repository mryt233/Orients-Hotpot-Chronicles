# 食材与切菜

火锅的灵魂是菜。这一页讲模组里的食材**从哪来**、**怎么加工**、**煮熟后回多少饥饿**。

{{icons:tripe,fatty_beef_roll,mutton_roll,beef_loin_slice,potato_slice,tofu_cube,beef_meatball,fish_ball,scallion,cilantro,soybean}}

:::tip
**所有生食材下锅都能涮熟**，也能放进熔炉、烟熏炉、营火里烤熟——「熟」之后每份回多少饥饿，在下面的表里。熟食**不能再下锅**。
:::

## 毛肚 {#tripe}

{{icons:tripe,cooked_tripe}}

- **来源**：杀牛或哞菇掉落，数量规则和原版牛肉一样（1～3 块，抢夺每级多 0～1，着火死的直接掉熟的）。
- **生毛肚**回 2 点饥饿，**熟毛肚**回 5 点。
- 涮火锅最合适：在锅里只要 2.5 秒左右就熟（比整块牛肉快一半）。

{{recipe:cooked_tripe}}

## 牛脊肉和吊龙 {#loin}{{since:0.1.3-alpha-hotfix1}}

{{icons:beef_loin,cooked_beef_loin,beef_loin_slice,cooked_beef_loin_slice}}

- **牛脊肉**：杀牛 / 哞菇有 **25%** 机率多掉一块（抢夺每级 +10%；着火死的掉熟牛脊肉）。生吃回 3 饥饿；整块烤熟成**熟牛脊肉**，回 8 点饥饿，和原版熟牛排一样。
- **吊龙**：把牛脊肉放在[砧板](#board)上用菜刀切，或放进**切石机**，一块切出 **3 片吊龙**。生的回 1 点饥饿；熟吊龙回 3 点饥饿。
- 吊龙在锅里**涮得最快**（和肥牛卷相比又快一半），涮几秒就熟。
- 熟牛脊肉不能再切。

{{recipe:beef_loin_slice,cooked_beef_loin}}

## 砧板、菜刀、擀面杖 {#board}{{since:0.1.2-alpha}}

要加工食材，先做三样厨具：

### 砧板

:::tip
砧板的**朝向**、**拿在手里看得见**、**对着板上食物只挖食物**、**物品栏图标不发暗**，都是 0.1.3-alpha-hotfix1 起才有的改进；0.1.2-alpha 里砧板没有朝向，拿在手里几乎看不见，板上的东西和砧板一起被挖。
:::

{{recipe:cutting_board}}

- **两个任意原木横着摆一排**，出 **2 块砧板**（原木种类不限）。
- **有朝向**：按你放的方向摆，板上的东西转到朝着你。
- **拿着能切、能捣的东西，右键砧板**，放上去一块；**空手右键**拿回来。
- 对着板上的东西**挖**，一下就挖掉，只掉那样东西，砧板留着。

### 铁菜刀

{{recipe:iron_kitchen_knife}}

方头的中式菜刀，耐久 250，**也能当武器**（伤害 4）。

### 擀面杖

{{recipe:rolling_pin}}

耐久 120，用来**捣丸子**。

## 切菜 {#cut}{{since:0.1.2-alpha}}

先把要切的东西放上砧板，**拿着铁菜刀右键砧板**，切一刀：

| 放上砧板 | 要几刀 | 切出来 | 熟的每份回 |
| --- | --- | --- | --- |
| {{i:minecraft:beef}} 生牛肉 | 1 刀 | 3 个{{i:fatty_beef_roll}} | 3 |
| {{i:minecraft:mutton}} 生羊肉 | 1 刀 | 3 个{{i:mutton_roll}} | 3 |
| {{i:beef_loin}} | 1 刀 | 3 片{{i:beef_loin_slice}} | 3 |
| {{i:minecraft:potato}} 土豆 | 3 刀，每刀 1 份 | 3 份{{i:potato_slice}}（每份是三片） | 2 |
| {{i:tofu}} 豆腐 | 1 刀 | 3 份{{i:tofu_cube}} | 2 |

**懒人做法**：这些东西丢进**切石机**，也能一次切好（整份直接出来）。

:::warn
0.1.2-alpha 里，**土豆和豆腐放不上砧板**（这是个已知问题，只能用切石机），0.1.3-alpha-hotfix1 修好。
:::

{{recipe:fatty_beef_roll,mutton_roll,potato_slice,tofu_cube}}

## 捣丸子 {#meatball}{{since:0.1.2-alpha}}

**能捣的肉**：生牛肉、生猪排、生羊肉、生鳕鱼、生鲑鱼。

1. 把肉放上砧板。
2. **拿着擀面杖右键砧板**，**捣三下**：
   - 第 1 下，肉被捶碎；
   - 第 2 下，变成肉浆；
   - 第 3 下，掉出 **3 个生丸子**。
3. 丸子是立体的小球，下锅涮熟；熟的每个回 **3** 点饥饿。

| 原料 | 生丸子 |
| --- | --- |
| 生牛肉 | {{i:beef_meatball}} |
| 生猪排 | {{i:pork_meatball}} |
| 生羊肉 | {{i:mutton_meatball}} |
| 生鳕鱼 / 生鲑鱼 | {{i:fish_ball}} |

### 香菜丸子

2 个生丸子 + 1 颗{{i:cilantro}}，在工作台里无序合成，得 **2 个**香菜丸子；四种丸子都有香菜版。熟的**每个回 4 点**饥饿，比普通的更好。

{{recipe:cilantro_beef_meatball}}

## 豆腐和黄豆 {#tofu}{{since:0.1.2-alpha}}

- **黄豆**：打**短草 / 高草**时，有 **15%** 掉一颗（不用剪刀）。
- **豆腐**：3 个黄豆 + 1 个水桶，工作台里无序合成，得 1 块豆腐，**水桶还给你**。
- 豆腐放上砧板一刀切成 3 块**豆腐块**，涮熟后每块回 2 点饥饿。

{{recipe:tofu}}

## 小葱和香菜 {#garnish}{{since:0.1.2-alpha}}

- 打**短草 / 高草的下半格**（不用剪刀），各有 **25%** 机率掉**小葱**和**香菜**。
- 都**能直接吃**，回 1 点饥饿；也是蘸料的原料（见[蘸料](sauce.html)），香菜还能做香菜丸子。
