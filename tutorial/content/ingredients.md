# 食材与切菜

火锅的灵魂是菜。这一页讲模组里的食材**从哪来**、**怎么加工**、**煮熟后回多少饥饿**。

{{icons:tripe,fatty_beef_roll,mutton_roll,beef_loin_slice,potato_slice,tofu_cube,beef_meatball,fish_ball,scallion,cilantro,soybean}}

:::tip
**所有生食材下锅都能涮熟**，也能放进熔炉、烟熏炉、营火里烤熟——熟了回多少饥饿见下面的表。熟食**不能再下锅**。
:::

## 毛肚 {#tripe}

{{icons:tripe,cooked_tripe}}

- **来源**：杀牛或哞菇掉落，数量规则和原版牛肉一样（1～3 块，抢夺每级多 0～1，着火死的直接掉熟的）。
- **生毛肚**回 2 点饥饿，**熟毛肚**回 5 点。
- 涮火锅最合适：在锅里只要 2.5 秒左右就熟（比整块牛肉快一半）。

{{recipe:cooked_tripe}}

## 牛脊肉和吊龙 {#loin}{{since:0.1.3-alpha-hotfix1}}

{{icons:beef_loin,cooked_beef_loin,beef_loin_slice,cooked_beef_loin_slice}}

- **牛脊肉**：杀牛或哞菇有 **25%** 概率多掉一块（抢夺每级 +10%；着火死的掉熟牛脊肉）。生吃回 3 饥饿；整块烤成熟牛脊肉回 8 点饥饿，和原版熟牛排一样。
- **吊龙**：把牛脊肉放[砧板](#board)上用菜刀切，或放进**切石机**，一块切出 **3 片吊龙**。生的回 1 点饥饿；熟的吊龙回 3 点饥饿。
- 吊龙在锅里**涮得最快**（比肥牛卷快一半），涮几秒就熟。
- 熟牛脊肉不能再切。

{{recipe:beef_loin_slice,cooked_beef_loin}}

## 砧板、菜刀、擀面杖 {#board}{{since:0.1.2-alpha}}

要加工食材，先做三样厨具：

### 砧板

:::tip
砧板的**朝向**、**拿在手里看得见**、**对着板上食物只挖食物**、**物品栏图标不发暗**，都是 0.1.3-alpha-hotfix1 起的改进；0.1.2-alpha 里砧板没有朝向，拿在手里几乎看不见，板上的东西和砧板一起被挖。
:::

{{recipe:cutting_board}}

- **两个任意原木横着摆一排**，出 **2 块砧板**。
- **有朝向**：按你放的方向摆，板上的东西转到朝着你。
- **拿能切、能捣的东西右键砧板**放上去；**空手右键**拿回来。
- 对着板上的东西**挖**，只掉那样东西，砧板留着。

### 铁菜刀

{{recipe:iron_kitchen_knife}}

方头中式菜刀，耐久 250，**也能当武器**（伤害 4）。

### 擀面杖

{{recipe:rolling_pin}}

耐久 120，用来**捣丸子**。

## 切菜 {#cut}{{since:0.1.2-alpha}}

把东西放上砧板，**拿铁菜刀右键砧板**切一刀：

| 放上砧板 | 要几刀 | 切出来 | 熟的每份回 |
| --- | --- | --- | --- |
| {{i:minecraft:beef}} | 1 刀 | 3 个 {{i:fatty_beef_roll}} | 3 |
| {{i:minecraft:mutton}} | 1 刀 | 3 个 {{i:mutton_roll}} | 3 |
| {{i:beef_loin}} | 1 刀 | 3 片 {{i:beef_loin_slice}} | 3 |
| {{i:minecraft:potato}} | 3 刀，每刀 1 份 | 3 份 {{i:potato_slice}}（每份三片） | 2 |
| {{i:tofu}} | 1 刀 | 3 块 {{i:tofu_cube}} | 2 |

**懒人做法**：丢进**切石机**也能一次切好。

:::warn
0.1.2-alpha 里土豆和豆腐放不上砧板（已知问题，只能用切石机），0.1.3-alpha-hotfix1 已修好。
:::

{{recipe:fatty_beef_roll,mutton_roll,potato_slice,tofu_cube}}

## 捣丸子 {#meatball}{{since:0.1.2-alpha}}

**能捣的肉**：生牛肉、生猪排、生羊肉、生鳕鱼、生鲑鱼。

1. 把肉放上砧板。
2. **拿擀面杖右键砧板捣三下**：第 1 下捶碎，第 2 下成肉浆，第 3 下出 **3 个生丸子**。
3. 丸子是立体小球，熟的每个回 **3** 点饥饿。

| 原料 | 生丸子 |
| --- | --- |
| 生牛肉 | {{i:beef_meatball}} |
| 生猪排 | {{i:pork_meatball}} |
| 生羊肉 | {{i:mutton_meatball}} |
| 生鳕鱼 / 生鲑鱼 | {{i:fish_ball}} |

### 香菜丸子

2 个生丸子 + 1 颗 {{i:cilantro}} 在工作台无序合成出 **2 个**香菜丸子（四种丸子都有香菜版）。熟的**每个回 4 点**饥饿。

{{recipe:cilantro_beef_meatball}}

## 虾、虾仁、虾滑 {#shrimp}{{since:0.1.4-alpha}}

{{icons:shrimp,peeled_shrimp,shrimp_paste}}

- **虾**：钓鱼有机会钓到，大约六分之一。
- **虾仁**：虾放砧板上用菜刀切；切石机也行。
- **虾滑**：虾仁用擀面杖在砧板上拍 3 下。
- 三样都能下锅涮、也能烤，熟的分别回 **3 / 3 / 4** 点饥饿；熟虾、熟虾仁的说明里还有一句小字。

{{recipe:peeled_shrimp,cooked_shrimp_paste}}

## 猪肉末和火腿肠 {#sausage}{{dev}}

{{icons:minced_pork,raw_ham_sausage,ham_sausage,ham_sausage_slice,cooked_ham_sausage_slice}}

:::dev
这套食材还没正式发布：**生猪排用菜刀切 → 1 份猪肉末；猪肉末 + 1 个原版小麦 → 3 根生火腿肠；加热 → 火腿肠；切一刀 → 3 片火腿肠片；切片再加热 → 熟火腿肠片**。切石机也能做两步切配。生火腿肠不能上砧板切，熟火腿肠片不能再下锅；擀面杖捣猪肉丸不变。

默认饥饿值：生火腿肠 **1**、火腿肠 **3**、火腿肠片 **1**、熟火腿肠片 **2**。猪肉末是加工原料，不是能直接吃的食物。完整做法和配方见[开发版预览](preview.html#sausage)。
:::

## 豆腐和黄豆 {#tofu}{{since:0.1.2-alpha}}

- **黄豆**：打**短草 / 高草**有 **15%** 掉一颗（不用剪刀）。
- **豆腐**：3 个黄豆 + 1 个水桶在工作台无序合成，得 1 块豆腐，**水桶还给你**。
- 豆腐放砧板上一刀切成 3 块**豆腐块**，涮熟每块回 2 点饥饿。

{{recipe:tofu}}

## 小葱和香菜 {#garnish}{{since:0.1.2-alpha}}

- 打**短草 / 高草下半格**（不用剪刀），各有 **25%** 掉**小葱**和**香菜**。
- **能直接吃**（回 1 点饥饿），也是[蘸料](sauce.html)原料，香菜还能做香菜丸子。
- 打草还会掉：**番茄**（做番茄锅底料）、**大蒜**（蒜泥的原料）、**黄豆**（做豆腐）。
- **熟海带**：原版海带丢进火锅里煮出来（熔炉、烟熏炉、营火照旧出干海带），回 2 点饥饿。
