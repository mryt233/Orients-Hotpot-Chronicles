# 常见问题

## 锅和灶台

**Q：锅里有汤，灶台为什么不点火？**
看三件事：① 灶膛里有没有燃料（右键砖身打开看）；② 锅是不是坐在灶台上；③ 汤倒进去了没有（没汤的锅不点火）。点火后锅会冒热气，汤面会沸腾。

**Q：灶台点着火，但是燃料没少？**
正常。只有**锅里有生食材要煮**时才耗燃料，只有汤没菜是「空烧」，不耗燃料（见[灶台与火锅](hotpot.html#fuel)）。

**Q：东西放不进锅里。**
锅里该放**能下锅的生食材**，熟食、辣椒 / 小米辣或被列入 `orients_hotpot_chronicles:not_pot_ingredient` 标签的物品放不进去。另外对着的那大格满了（9 小格）也放不进去，换个大格试试。

**Q：想换汤底怎么办？**
拿**空桶右键锅**把汤舀回桶里（有菜先取出来）。菌汤要用碗舀，而且锅里没菜才行。

**Q：锅里的东西怎么都不熟？**
- 锅是不是「冷锅」（不在点着的灶台或篝火上）？冷锅不会煮熟。
- 火力：木头 ×0.65、煤炭 ×1.0、岩浆桶 ×1.6；汤底：高汤最慢、红汤最快。木头烧 + 高汤会很慢。
- 食材烹饪时间不同：整块牛肉 5 秒，肥牛卷 2.5 秒，吊龙约 1 秒多（见[配方大全](recipes.html)的烹饪与锅中专煮表）。

**Q：吃东西突然反胃了。**
在开启惩罚（完整模式默认）时，吃了**冷锅**里的东西有 30% 概率反胃 15 秒。喝一瓶**植物蛋白饮料**、一碗**清汤**或蘸**醋**能解；若不喜欢这类惩罚，可在模组设置顶部切换到**精简模式**，或在「▸ 自定义细项」关闭「冷锅反胃与辣惩罚」。

**Q：放高灶台提示放不下 / 有锅时点不到灶膛？**
高灶台占头顶一格，把上面一格清空。放上锅后，如果只想打开灶膛添燃料，直接右键**高灶台下半截砖体**即可稳定打开。

**Q：锅怎么收起来？**
灶台上的锅：空手 **Shift + 右键**，整锅连汤带菜进背包，放下原样恢复；直接挖也行，碎屑和掉落物会按锅的位置出现在锅所在高度。

## 桌椅、备菜架和餐具

**Q：以前版本的 40 张木头/石料火锅桌去哪了？怎么做新外观？**
`0.3.1-alpha` 起全部收束为通用**火锅桌**（{{i:hotpot_table}}）和**高火锅桌**（{{i:tall_hotpot_table}}）。升级旧存档时已摆放和背包里的旧桌会自动迁移并保留原外观。想换材质时，**手拿任意实心不透明方块直接右键桌面（上半）或底座（下半）**即可 1 进 1 出无损换装（潜行空手拆出），见[桌子、备菜架与凳子](tables.html#swap_materials)。

**Q：凳子坐不上去。**
空手（或手里拿不是方块的东西）右键。两个人之间要隔一整格；旁边有人就挪一格坐；手持模组作物也能直接坐凳子。

**Q：盘子放不下 / 一格摆不下更多了。**
盘子不能重叠。小碟一格最多 5 个，长盘一格 2 个，方盘一格 1 个，混放看占的地方。

**Q：高桌上的东西点不中。**
模组已经处理了：准星对着桌面上的盘子也能选到。真点不中，往旁边一点或蹲下试试。

**Q：想把桌上的盘子整个拿走。**
空手右键盘子整盘拿起来；挖也可以，只会挖对着的那一个。

## 食材、果树与加工

**Q：怎么得到毛肚、牛脊肉和生鸡爪？**
杀牛或哞菇掉**毛肚**（25% 额外掉**牛脊肉**）；杀成年鸡有 50% 概率掉 1～2 个**生鸡爪**（着火死掉熟鸡爪）。

**Q：为什么打原版橡木树叶不掉橙子了？黄豆、小葱、香菜怎么得？**
`0.3.1-alpha` 起新增了**独立橙子树**与 **9 种可种植作物**：
- **橙子**：在森林、繁花森林、平原、草甸与丛林找到自然生成的矮橙子树（或用橙子树苗种一棵），等橙叶长成挂果后直接空手右键采摘。
- **9 种作物**（小葱、香菜、黄豆、大蒜、番茄、辣椒、花生、青菜、折耳根）：可在对应群系野外采**野生植株**，也可直接拿成品对着**耕地右键播种**（支持骨粉）；开启「独立作物替代打草」（完整模式默认）时，打草仅保留 **2%** 稀疏找种兜底。如果喜欢旧版高掉率打草，在设置里关闭该选项或切换至**精简模式**即可恢复。

**Q：小石磨怎么用？豆浆怎么自动流进开口大木桶？**
1. 拿 2 颗黄豆右键放进小石磨顶斗，再拿水桶倒水蓄能（1 桶水默认磨 3 次），空手连续右键推磨 4 圈即可磨出豆浆（干磨花生、辣椒、大蒜则不用倒水）。
2. 如果你把**空的开口大木桶（{{i:wooden_vat}}）紧挨着小石磨出料口正前方**摆放，最后一圈磨完时豆浆会自动从磨嘴流进木桶（不用拿空桶接来接去）；若单独摆放石磨，用**空铁桶**右键磨槽盛出{{i:soymilk_bucket}}再倒进大木桶即可。大木桶里加入{{i:brine_bottle}}并盖上{{i:wooden_press_lid}}，等 4 秒压出 2 块冷豆腐；精简模式（或关闭「细致豆腐工序」）可直接用黄豆 + 水桶合成冷豆腐。

**Q：砧板放不上东西。**
能切或能捣的生食才可放上砧板：切配有生牛肉、生羊肉、生猪排、牛脊肉、土豆、冷/热豆腐、虾、火腿肠、辣椒、莲藕、生鱿鱼、折耳根与生鸡爪；捣制有生肉（牛/猪/羊/鳕/鲑）、大蒜、虾仁、花生与折耳根。熟火腿肠以外的熟食与成品不可重复下板。

## 光影、画质与模组兼容

**Q：开了光影和性能优化模组，橙子树、作物和锅灶有什么特别适配？**
- 核心硬表面、锅灶（含火口余烬自发光）、餐具与汤面内置 `LabPBR 1.3` 法线/高光副图（`_n` / `_s`），兼顾原版、Sodium 与 Iris / BSL 等光影表现；
- 橙子树叶遵循原版「**流畅 / 高品质**」画质开关切换实心林荫底与透明镂空，并自动向 Iris 光影注入橙子树叶、橙子树苗、9 种作物与野生植株的植物摇曳映射。

**Q：安装了 JEI、REI 16、Jade 或 Axiom 等模组能兼容吗？**
完全兼容：JEI 与 **REI 16**（含 Fabric / NeoForge）可正常展示火锅涮煮、砧板切配、擀面杖捣制、小石磨研磨与开口大木桶压制五类配方及蘸料台原料表避让区；**Jade** 可查看锅内汤底/进度/辣度、分部位桌架材质及木桶液量；创造模式物品栏左侧也会自动避让 Axiom 等外置工具条。

## 完整/精简模式与数值配置 {#config}{{since:0.2.0-alpha}}

**Q：觉得工序太多想轻松点玩，能简化吗？能改数值吗？**
能。直接从**模组列表**（Fabric 需装 Mod Menu，NeoForge / Forge 原生自带）选中本模组点「**配置**」：
- **模式切换（0.3.1-alpha 起）**{{since:0.3.1-alpha}}：界面顶部提供「**完整模式 / 精简模式**」一键切换与「▸ 自定义细项」6 个独立开关（`细致豆腐工序`、`冷锅与辣惩罚`、`独立作物替代打草`、`即时小游戏`、`备菜架换材质`、`精简模式折叠指南次要细节`）；切换模式**绝不会删除任何物品或损坏存档**，游戏内火锅指南底部会显示当前模式并联动折叠对应说明与配方。管理员也可执行 `/orientshotpot mode [full|simple]`。
- **直接改配置文件**：也可编辑 `config/orients_hotpot_chronicles.json` 并由管理员执行 **`/orientshotpot reload`** 热重载，无需重启即生效；旧版本遗留废弃键会自动静默清理。
- **多人服**只改服务端，玩家进服、模式切换和重载时会自动同步。
- 某一项写错（不是数字、超范围、键名拼错）只回退那一项并警告；整个文件写坏就全部用默认值，**坏文件原样保留**方便修。
- 配方与曲谱用数据包改，再执行原版 `/reload`；`loot.*` 掉率修改后同样需执行一次原版 `/reload` 才会按新概率重建战利品池。
- 重载后，**已经下锅的食材保留已煮的进度**，剩余时间按新数值重算；`cooking.items.<物品>` 只管本模组自己的食材，原版和其他模组的食材按它们自己的烹饪配方煮。

### 设置界面怎么用 {#screen}

{{since:0.2.2-alpha}}界面顶部为**模式预设栏与自定义细项抽屉**，下方分**常用**和**高级**两张页签，打开时停在**常用**：

- **常用**只放玩家最常动的几项——最上面是**烟雾粒子强度**滑块（另有 0% / 50% / 100% 三个快捷档），下面是**煤炭档灶火功率**（整体涮煮快慢的总闸）、**涮煮兜底时间**，以及**红汤 / 清汤 / 高汤的加热倍率**。
- **高级**把其余全部按分类收进 **18 个可折叠分组**（模式与机制、作物与果树、食材加工、桌架换材质、即时小游戏、涮煮时间、食材涮煮时间、汤底加热倍率、燃料档位、汤碗、蘸料、饮料、食物营养、围锅回血、冷锅反胃、碰杯干杯、红汤辣度、战利品掉率），默认收起，点分组标题展开。
- **改数值**：每行是 `- 数值 单位 +`。点一次走一步，**按住 Shift 点一次走 10 步**；**点数值框可以直接敲数字**，敲成非数字或超出范围会**标红，且不让保存**。
- **单位**：时间按 tick 显示（20 tick = 1 秒，够宽时后面还会折算成秒），倍率写「倍」，饥饿、经验写「点」，效果等级写「级」，半径距离写「格」。
- **单项 / 全部恢复**：改过的行右边会出现 **↺** 单项重置；底部「恢复默认」点一次会变成「再点一次确认」，4 秒内再点一次全部恢复（并重置粒子强度为 100%）。
- **保存失败提示**：写不进配置文件时界面停在当前页说明原因；原文件损坏时先备份成 `orients_hotpot_chronicles.json.broken-<时间>` 再保存并提示备份名。

## 数据包 / 子模组加汤底和蘸料 {{since:0.3.0-alpha}} {#custom_soup_sauce}<!--清单#154-->

自 **0.3.0-alpha** 起，除了修改内置数值和锅内煮法，汤底和蘸料也支持通过数据包或 Java 子模组新增与覆盖：

- **数据包配方路径与重载**：在数据包中放置 `data/<命名空间>/recipe/soup/<名称>.json`（配方类型 `orients_hotpot_chronicles:soup_base`）可新增或覆盖汤底，放置 `data/<命名空间>/recipe/seasoning/<名称>.json`（配方类型 `orients_hotpot_chronicles:seasoning`）可新增或覆盖蘸料；最终登记 ID 会自动剥去 `soup/` 或 `seasoning/` 目录前缀（例如 `<命名空间>:<名称>`）。保存后执行 `/reload` 即可热重载，联机时服务端会自动同步到客户端（不列入原版配方书）。
- **覆盖优先级**：数据包只需填写要调整的部分字段就能覆盖内置汤底或蘸料；但玩家在 `config/orients_hotpot_chronicles.json` 或设置界面中**显式修改过的内置数值**优先级最高，不会被数据包覆盖（配置 > 数据包 > 代码默认）。第三方命名空间条目只由数据包或子模组定义，不读写本模组内置配置文件。
- **通用汤碗与外观着色**：子模组可为新增汤底提供专属碗物品与汤面贴图（`assets/<ns>/textures/block/hot_pot_top_<path>[_boiling].png`）；没有专属碗物品的汤底盛出时会装入{{i:soup_bowl}}通用汤碗 `orients_hotpot_chronicles:soup_bowl`，通过 `orients_hotpot_chronicles:soup` 数据组件记录汤底 ID 并继承对应效果。纯 JSON 数据包无需额外贴图，锅面会按 `screen_colors.base`、沸腾气泡按 `bubble_colors.body` 着色渲染清汤基底；若之后移除数据包或子模组，已有方块和碗中的原始 ID 数据会保留，界面与汤面显示为未知占位。
- **子模组 Java 登记**：附属模组可在启动注册冻结前调用 `Soups.register(...)` 与 `Seasonings.register(...)` 注册条目，详细字段与格式见仓库内的 `mod/docs/开放登记说明.md`（`mod/content/materials.json` 仅作本模组内置材质与内置汤底静态生成器的唯一事实来源，无需修改）。
