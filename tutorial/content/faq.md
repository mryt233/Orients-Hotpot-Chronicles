# 常见问题

## 锅和灶台

**Q：锅里有汤，灶台为什么不点火？**
看三件事：① 灶膛里有没有燃料（右键灶台砖身打开看）；② 锅是不是真的坐在灶台上；③ 汤是不是倒进去了（没有汤的锅不会点火）。点火后锅里会冒热气、汤面会沸腾。

**Q：灶台点着火，但是燃料没少？**
正常。只有**锅里有生食材要煮**的时候才耗燃料，只有汤没有菜是「空烧」，不耗燃料（见[灶台与火锅](hotpot.html#fuel)）。

**Q：东西放不进锅里。**
锅里该放**食物**，熟食不能再下锅（0.1.3-alpha-hotfix1 起，木头、铁器、矿石也彻底放不进去）。另外准星对着的那个大格满了（9 小格）也放不进去，换一个大格试试。

**Q：想换汤底怎么办？**
拿**空桶右键锅**，把汤舀回桶里（锅里有菜的话先把菜取出来）。菌汤要用碗舀，还要求锅里没有菜。

**Q：锅里的东西怎么都不熟？**
- 锅是不是「冷锅」（不在点着的灶台或篝火上）？冷锅是不会煮熟的。
- 火力：木头 ×0.65、煤炭 ×1.0、岩浆桶 ×1.6；汤底：高汤最慢、红汤最快。木头烧 + 高汤，会很慢。
- 食材本身的烹饪时间不一样：整块牛肉 5 秒，肥牛卷 2.5 秒（吊龙约 1 秒多；见[配方大全](recipes.html)的烹饪表）。

**Q：吃东西突然反胃了。**
你吃的是**冷锅**里的东西，有 30% 概率反胃 15 秒。喝一瓶**植物蛋白饮料**、一碗**清汤**或**醋**蘸料能解。

**Q：放高灶台提示放不下。**
高灶台要占头顶一格，请把上面一格清空。

**Q：锅怎么收起来？**
灶台上的锅：空手 **Shift + 右键**，整锅连汤带菜进背包，放下去原样恢复（单独摆放 / 篝火上的锅，0.1.3-alpha-hotfix1 起才能这样拿）。也可以直接挖（锅有硬度，灶台是灶台的）。

## 桌椅和餐具

**Q：凳子坐不上去。**
空手（或手里拿的不是方块）右键。两个人之间要隔一整格；旁边已有人坐了的话，挪一格试试。

**Q：盘子放不下 / 一格摆不下更多了。**
盘子不能重叠。小碟一格最多 5 个，长盘一格 2 个，方盘一格 1 个，混放时看占用的空间。

**Q：高桌上的东西点不中。**
本模组已经处理了：准星对着桌面上的盘子也能选中。如果真的点不中，往旁边一点或蹲下试试。

**Q：想把桌上的盘子整个拿走。**
空手右键盘子，整盘（连菜）拿起来；挖也可以，只会挖对着的那一个。

## 食材

**Q：怎么得到毛肚？**
杀牛或哞菇掉落。

**Q：怎么得到黄豆、小葱、香菜？**
**打短草 / 高草**（不要用剪刀）。小葱、香菜各 25%，黄豆 15%。

**Q：砧板放不上东西。**
只有**能切 / 能捣**的东西能放：生牛肉、生羊肉、牛脊肉、土豆、豆腐（0.1.2-alpha 这两样放不上，用切石机），以及能捣丸子的生猪排、鳕鱼、鲑鱼。熟的不行。

**Q：为什么饮料没有合成配方？**
目前饮料只能在创造物品栏拿，或用指令 `/give`。以后可能会加做法。

## 存档和版本

**Q：旧存档里的灶台、盘子、凳子没了。**
0.1.0-alpha.1 的存档升级后，一部分物品会丢失或变样（当时有一次物品 ID 大改名）。0.1.1-alpha 之后，旧 ID 大部分能认回来，旧板凳会变成条凳。**升级前一定备份存档**，alpha 阶段建议新存档。

**Q：这个模组能和别的模组联动吗？**
目前留了接口：方块标签 `orients_hotpot_chronicles:heat_sources` 里的方块，可以当作锅的热源。其他联动欢迎在 GitHub 上提建议。

**Q：1.20.1、NeoForge 版和 1.21.1 Fabric 有什么区别？**
玩法一样，只有热气粒子、吃完还碗这类很小的差别，但**新内容通常 Fabric 1.21.1 先有，其他版本晚一步**。详见[下载、安装与反馈](install.html#ports)。

**Q：发现 bug 去哪里报？**
去项目的 GitHub：<https://github.com/mryt233/Orients-Hotpot-Chronicles>，在 Issues 里写清楚（也可以进 **QQ 交流群 248314791**，联系方式见[下载、安装与反馈](install.html#feedback)）。请写清楚：Minecraft 版本、模组版本、怎么触发、最好有截图。
