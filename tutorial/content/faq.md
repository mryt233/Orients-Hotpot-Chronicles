# 常见问题

## 锅和灶台

**Q：锅里有汤，灶台为什么不点火？**
看三件事：① 灶膛里有没有燃料（右键砖身打开看）；② 锅是不是坐在灶台上；③ 汤倒进去了没有（没汤的锅不点火）。点火后锅会冒热气，汤面会沸腾。

**Q：灶台点着火，但是燃料没少？**
正常。只有**锅里有生食材要煮**时才耗燃料，只有汤没菜是「空烧」，不耗燃料（见[灶台与火锅](hotpot.html#fuel)）。

**Q：东西放不进锅里。**
锅里该放**食物**，熟食不能再下锅（0.1.3-alpha-hotfix1 起木头、铁器、矿石也彻底放不进去）。另外对着的那大格满了（9 小格）也放不进去，换个大格试试。

**Q：想换汤底怎么办？**
拿**空桶右键锅**把汤舀回桶里（有菜先取出来）。菌汤要用碗舀，而且锅里没菜才行。

**Q：锅里的东西怎么都不熟？**
- 锅是不是「冷锅」（不在点着的灶台或篝火上）？冷锅不会煮熟。
- 火力：木头 ×0.65、煤炭 ×1.0、岩浆桶 ×1.6；汤底：高汤最慢、红汤最快。木头烧 + 高汤会很慢。
- 食材烹饪时间不同：整块牛肉 5 秒，肥牛卷 2.5 秒，吊龙约 1 秒多（见[配方大全](recipes.html)的烹饪表）。

**Q：吃东西突然反胃了。**
吃了**冷锅**里的东西，有 30% 概率反胃 15 秒。喝一瓶**植物蛋白饮料**、一碗**清汤**或蘸**醋**能解。

**Q：放高灶台提示放不下。**
高灶台占头顶一格，把上面一格清空。

**Q：锅怎么收起来？**
灶台上的锅：空手 **Shift + 右键**，整锅连汤带菜进背包，放下原样恢复（单放或篝火上的锅 0.1.3-alpha-hotfix1 起也行）。直接挖也行。

## 桌椅和餐具

**Q：凳子坐不上去。**
空手（或手里拿不是方块的东西）右键。两个人之间要隔一整格；旁边有人就挪一格坐。

**Q：盘子放不下 / 一格摆不下更多了。**
盘子不能重叠。小碟一格最多 5 个，长盘一格 2 个，方盘一格 1 个，混放看占的地方。

**Q：高桌上的东西点不中。**
模组已经处理了：准星对着桌面上的盘子也能选到。真点不中，往旁边一点或蹲下试试。

**Q：想把桌上的盘子整个拿走。**
空手右键盘子整盘拿起来；挖也可以，只会挖对着的那一个。

## 食材

**Q：怎么得到毛肚？**
杀牛或哞菇掉落。

**Q：怎么得到黄豆、小葱、香菜？**
**打短草 / 高草**（不要用剪刀）。小葱、香菜各 25%，黄豆 15%。

**Q：砧板放不上东西。**
只有**能切 / 能捣**的东西能放：生牛肉、生羊肉、牛脊肉、土豆、豆腐（0.1.2-alpha 这两样放不上，用切石机），以及捣丸子的生猪排、鳕鱼、鲑鱼。熟的不行。

**Q：为什么饮料没有合成配方？**
0.1.4-alpha 已经有了。橙子饮料用橙子、植物蛋白饮料用黄豆、之晗可乐用可可豆和蜂蜜，见[盘子、碗与饮料](tableware.html#drink)。

## 存档和版本

**Q：旧存档里的灶台、盘子、凳子没了。**
0.1.0-alpha.1 存档升级后部分物品会丢失或变样（当时物品 ID 大改名）。0.1.1-alpha 后大部分能认回来，旧板凳会变条凳。**升级前一定备份存档**，建议新存档玩。

**Q：这个模组能和别的模组联动吗？**
留了接口：方块标签 `orients_hotpot_chronicles:heat_sources` 里的方块能当锅的热源。其他联动欢迎去 GitHub 提建议。

**Q：1.20.1、26.1.x、26.2 版和 1.21.1 有什么区别？**
0.2.2-alpha 起（0.3.0-alpha 同步收口）**1.21.1（Fabric / NeoForge）、1.20.1（Fabric / Forge）、26.1.x（Fabric / NeoForge）和 26.2（Fabric / NeoForge）** 全部同步更新，玩法与内容一致。详见[下载、安装与反馈](install.html#ports)。

去 GitHub：<https://github.com/mryt233/Orients-Hotpot-Chronicles> 提 Issue（也可以进 **QQ 群 248314791**，联系方式见[下载、安装与反馈](install.html#feedback)）。请写清：游戏版本、模组版本、怎么触发、最好有截图。

## 数值配置 {#config}{{since:0.2.0-alpha}}

**Q：能改食物回多少饥饿、汤底多快吗？**
能。0.2.2-alpha 起可以直接从**模组列表**（Fabric 需装 Mod Menu，NeoForge / Forge 原生自带）选中本模组点「**配置**」调整并保存；也可以直接改 `config/orients_hotpot_chronicles.json` 配置文件（里面能调食物营养、饮料每口营养、汤底速度、燃料和蘸料等数值，每项都写了含义、范围和单位）。改完配置文件由管理员执行 **`/orientshotpot reload`**，不用重启就生效；回执会报告有几条警告。

- **多人服**只改服务端，玩家进服和重载时会自动同步。
- 某一项写错（不是数字、超范围、键名拼错）只回退那一项并警告；整个文件写坏就全部用默认值，**坏文件原样保留**方便修。
- 配方用数据包改，再执行原版 `/reload`。
- {{since:0.3.0-alpha}}锅专用的煮法、擀面杖捣制也能用数据包改（配方类型 `pot_boiling`、`pounding`）；不让下锅的东西加进物品标签 `orients_hotpot_chronicles:not_pot_ingredient`。<!-- mryt233 改（2026-11-11） -->
- {{since:0.3.0-alpha}}重载后，**已经下锅的食材保留已煮的进度**，剩余时间按新数值重算。
- {{since:0.3.0-alpha}}`cooking.items.<物品>` 只管本模组自己的食材；原版和其他模组的食材按它们自己的烹饪配方煮。
- {{since:0.3.0-alpha}}新增可调项：**围锅回血**（`warmth.*`）、**冷锅反胃**（`cold_pot.*`）、**碰杯干杯**（`cheers.*`）、**红汤辣度**（`spicy.*`）与**战利品掉率**（`loot.*`）；其中前四类执行 `/orientshotpot reload`（或在设置界面保存）即生效，**修改 `loot.*` 后还需执行一次原版 `/reload`（或重启存档/服务器）**才会按新概率重建战利品池。
- 教程里写的数值都是默认值，服务器改过配置以服务器为准。

### 设置界面怎么用 {#screen}

{{since:0.2.2-alpha}}界面分**常用**和**高级**两张页签，打开时停在**常用**：

- **常用**只放玩家最常动的几项——最上面是**烟雾粒子强度**滑块（另有 0% / 50% / 100% 三个快捷档），下面是**煤炭档灶火功率**（整体涮煮快慢的总闸）、**涮煮兜底时间**，以及**红汤 / 清汤 / 高汤的加热倍率**。
- **高级**把其余全部按分类收进**可折叠分组**（涮煮时间、食材涮煮时间、汤底加热倍率、燃料档位、汤碗、蘸料、饮料、食物营养，{{since:0.3.0-alpha}}以及围锅回血、冷锅反胃、碰杯干杯、红汤辣度、战利品掉率），默认收起，点分组标题展开。
- **改数值**：每行是 `- 数值 单位 +`。点一次走一步，**按住 Shift 点一次走 10 步**；**点数值框可以直接敲数字**，敲成非数字或超出范围会**标红，且不让保存**。
- **单位**：时间按 tick 显示（20 tick = 1 秒，够宽时后面还会折算成秒），倍率写「倍」，饥饿、经验写「点」，效果等级写「级」，{{since:0.3.0-alpha}}半径距离写「格」。
- **单项恢复**：改过的那行右边会出现 **↺**，点它只把这一项恢复成默认值；没改的行不显示。
- **全部恢复**：底部「恢复默认」点一次会变成「**再点一次确认**」，4 秒内再点一次才真的全部恢复（同时把粒子强度退回 100%）。
- **看说明**：鼠标停在任意一行上，会有一句白话说明加上「范围 x～y，默认 z」。
- 内容多时用**滚轮**或右侧滚动条；**保存并生效**才写回配置文件并热重载，按 ESC / 点「取消」则全部改动不保留（粒子强度会退回进界面前的值）。
- {{since:0.3.0-alpha}}**保存失败**：写不进配置文件时界面停在当前页说明原因——「改动只在本次游戏有效」或「没能应用改动，原配置文件已保留」；原配置文件已写坏时，会先备份成 `orients_hotpot_chronicles.json.broken-<时间>` 再保存，界面显示备份名，核对后再关闭。

## 数据包 / 子模组加汤底和蘸料 {{since:0.3.0-alpha}} {#custom_soup_sauce}<!--清单#154-->

自 **0.3.0-alpha** 起，除了修改内置数值和锅内煮法，汤底和蘸料也支持通过数据包或 Java 子模组新增与覆盖：

- **数据包配方路径与重载**：在数据包中放置 `data/<命名空间>/recipe/soup/<名称>.json`（配方类型 `orients_hotpot_chronicles:soup_base`）可新增或覆盖汤底，放置 `data/<命名空间>/recipe/seasoning/<名称>.json`（配方类型 `orients_hotpot_chronicles:seasoning`）可新增或覆盖蘸料；最终登记 ID 会自动剥去 `soup/` 或 `seasoning/` 目录前缀（例如 `<命名空间>:<名称>`）。保存后执行 `/reload` 即可热重载，联机时服务端会自动同步到客户端（不列入原版配方书）。
- **覆盖优先级**：数据包只需填写要调整的部分字段就能覆盖内置汤底或蘸料；但玩家在 `config/orients_hotpot_chronicles.json` 或设置界面中**显式修改过的内置数值**优先级最高，不会被数据包覆盖（配置 > 数据包 > 代码默认）。第三方命名空间条目只由数据包或子模组定义，不读写本模组内置配置文件。
- **通用汤碗与外观着色**：子模组可为新增汤底提供专属碗物品与汤面贴图（`assets/<ns>/textures/block/hot_pot_top_<path>[_boiling].png`）；没有专属碗物品的汤底盛出时会装入{{i:soup_bowl}}通用汤碗 `orients_hotpot_chronicles:soup_bowl`，通过 `orients_hotpot_chronicles:soup` 数据组件记录汤底 ID 并继承对应效果。纯 JSON 数据包无需额外贴图，锅面会按 `screen_colors.base`、沸腾气泡按 `bubble_colors.body` 着色渲染清汤基底；若之后移除数据包或子模组，已有方块和碗中的原始 ID 数据会保留，界面与汤面显示为未知占位。
- **子模组 Java 登记**：附属模组可在启动注册冻结前调用 `Soups.register(...)` 与 `Seasonings.register(...)` 注册条目，详细字段与格式见仓库内的 `mod/docs/开放登记说明.md`（`mod/content/materials.json` 仅作本模组内置材质与内置汤底静态生成器的唯一事实来源，无需修改）。
