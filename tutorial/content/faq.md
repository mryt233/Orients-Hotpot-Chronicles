# 常见问题

## 锅和灶台

**Q：锅里有汤，灶台为什么不点火？**
看三件事：① 灶膛里有没有燃料（右键砖身打开看）；② 锅是不是坐在灶台上；③ 汤倒进去了没有（没汤的锅不点火）。点火后锅会冒热气，汤面会沸腾。

**Q：灶台点着火，但是燃料没少？**
正常。只有**锅里有生食材要煮**时才耗燃料，只有汤没菜是「空烧」，不耗燃料（见[灶台与火锅](hotpot.html#fuel)）。

**Q：东西放不进锅里。**
锅里该放**食物**，熟食不能再下锅（0.1.3-alpha-hotfix1 起木头、铁器、矿石也彻底放不进去）。另外对着的那大格满了（9 小格）也放不进去，换个大格试试。

**Q：想换汤底怎么办？**
拿**空桶右键锅**把汤舀回桶里（有菜先取出来）。菌汤要用碗舀，而且锅里没菜才行。

**Q：锅里的东西怎么都不熟？**
- 锅是不是「冷锅」（不在点着的灶台或篝火上）？冷锅不会煮熟。
- 火力：木头 ×0.65、煤炭 ×1.0、岩浆桶 ×1.6；汤底：高汤最慢、红汤最快。木头烧 + 高汤会很慢。
- 食材烹饪时间不同：整块牛肉 5 秒，肥牛卷 2.5 秒，吊龙约 1 秒多（见[配方大全](recipes.html)的烹饪表）。

**Q：吃东西突然反胃了。**
吃了**冷锅**里的东西，有 30% 概率反胃 15 秒。喝一瓶**植物蛋白饮料**、一碗**清汤**或蘸**醋**能解。

**Q：放高灶台提示放不下。**
高灶台占头顶一格，把上面一格清空。

**Q：锅怎么收起来？**
灶台上的锅：空手 **Shift + 右键**，整锅连汤带菜进背包，放下原样恢复（单放或篝火上的锅 0.1.3-alpha-hotfix1 起也行）。直接挖也行。

## 桌椅和餐具

**Q：凳子坐不上去。**
空手（或手里拿不是方块的东西）右键。两个人之间要隔一整格；旁边有人就挪一格坐。

**Q：盘子放不下 / 一格摆不下更多了。**
盘子不能重叠。小碟一格最多 5 个，长盘一格 2 个，方盘一格 1 个，混放看占的地方。

**Q：高桌上的东西点不中。**
模组已经处理了：准星对着桌面上的盘子也能选到。真点不中，往旁边一点或蹲下试试。

**Q：想把桌上的盘子整个拿走。**
空手右键盘子整盘拿起来；挖也可以，只会挖对着的那一个。

## 食材

**Q：怎么得到毛肚？**
杀牛或哞菇掉落。

**Q：怎么得到黄豆、小葱、香菜？**
**打短草 / 高草**（不要用剪刀）。小葱、香菜各 25%，黄豆 15%。

**Q：砧板放不上东西。**
只有**能切 / 能捣**的东西能放：生牛肉、生羊肉、牛脊肉、土豆、豆腐（0.1.2-alpha 这两样放不上，用切石机），以及捣丸子的生猪排、鳕鱼、鲑鱼。熟的不行。

**Q：为什么饮料没有合成配方？**
0.1.4-alpha 已经有了。橙子饮料用橙子、植物蛋白饮料用黄豆、之晗可乐用可可豆和蜂蜜，见[盘子、碗与饮料](tableware.html#drink)。

## 存档和版本

**Q：旧存档里的灶台、盘子、凳子没了。**
0.1.0-alpha.1 存档升级后部分物品会丢失或变样（当时物品 ID 大改名）。0.1.1-alpha 后大部分能认回来，旧板凳会变条凳。**升级前一定备份存档**，建议新存档玩。

**Q：这个模组能和别的模组联动吗？**
留了接口：方块标签 `orients_hotpot_chronicles:heat_sources` 里的方块能当锅的热源。其他联动欢迎去 GitHub 提建议。

**Q：1.20.1、26.1.x、26.2 版和 1.21.1 有什么区别？**
0.2.2-alpha 起 **1.21.1（Fabric / NeoForge）、1.20.1（Fabric / Forge）、26.1.x（Fabric / NeoForge）和 26.2（Fabric / NeoForge）** 全部同步更新，玩法与内容一致。详见[下载、安装与反馈](install.html#ports)。

## 数值配置 {#config}{{since:0.2.0-alpha}}

**Q：能改食物回多少饥饿、汤底多快吗？**
能。0.2.2-alpha 起可以直接从**模组列表**（Fabric 需装 Mod Menu，NeoForge / Forge 原生自带）选中本模组点「**配置**」，用滑块按分类调整并保存；也可以直接改 `config/orients_hotpot_chronicles.json` 配置文件（里面能调食物营养、饮料每口营养、汤底速度、燃料和蘸料等数值，每项都写了含义、范围和单位）。改完配置文件由管理员执行 **`/orientshotpot reload`**，不用重启就生效；回执会报告有几条警告。

- **多人服**只改服务端，玩家进服和重载时会自动同步。
- 某一项写错（不是数字、超范围、键名拼错）只回退那一项并警告；整个文件写坏就全部用默认值，**坏文件原样保留**方便修。
- 配方用数据包改，再执行原版 `/reload`。
- 教程里写的数值都是默认值，服务器改过配置以服务器为准。
