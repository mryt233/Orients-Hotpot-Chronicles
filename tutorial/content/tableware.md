# 盘子、碗与饮料

火锅桌上要摆满：盘子装生菜，碗盛汤，饮料解辣，筷子夹菜。

## 盘子 {#plate}

### 盘子的种类

**5 种材质 × 6 种大小 = 30 种盘子**：

| 材质 | 做小碟用的原料 |
| --- | --- |
| 石英 | {{i:minecraft:quartz}} |
| 竹编 | {{i:minecraft:bamboo}} |
| 红陶 | {{i:minecraft:brick}} |
| 铜 | {{i:minecraft:copper_ingot}} |
| 铁 | {{i:minecraft:iron_ingot}} |

| 大小 | 样子 | 能装几样菜 |
| --- | --- | --- |
| 小碟（1×1） | 一格 | 3 样 |
| 双格盘（1×2） | 两格长 | 6 样 |
| 三格长盘（1×3） | 三格长 | 9 样 |
| 四格方盘（2×2） | 方的 | 12 样 |
| 五格长盘（1×5） | 五格长 | 15 样 |
| 八格大盘（2×4） | 大的 | 24 样 |

每一**格**最多装 3 样菜（任何菜都行），盘子容量 = 格数 × 3。

### 摆放 {#place}

- 拿盘子**右键桌面或地面**就摆上去了。
- 一格空间里可以**摆好几个**，不能重叠，不同样能混着放：小碟一格 5 个、长盘一格 2 个、方盘一格 1 个。
- 盘子会自动贴桌面：矮桌上下移 5 像素，高桌上上移 7 像素。

### 往盘子里放菜和拿菜 {#use}

操作都对**准星对着的那一个盘子**生效：

| 你手里拿着 | 右键盘子 |
| --- | --- |
| 盘子 | 再摆一个盘子 |
| 食物 | 放一样菜进盘子（一格最多 3 样） |
| 竹筷 | 夹走**最后放的**菜；竹筷夹着熟菜时右键盘子 = **吃掉**，吃饱了吃不下才放回 |
| 空手 | **把盘子（连菜）拿起来** |
| 空手 + 潜行 | 取出最后放的一样菜到背包（盘子留着） |

- **挖盘子**：只挖对着的那个，菜会一起掉出来。
- **鼠标中键**：复制准星对着的盘子，**连菜一起**。
- 装了菜的盘子，物品栏图标和拿在手里都会画出里面的菜；提示像收纳袋，同样的菜合并写「×数量」。
- **端着菜下锅**：拿装了菜的盘子右键锅，里面的**生食材**倒进锅，熟的留在盘里。

## 碗和汤碗 {#bowl}

### 碗的新用法

普通的**碗**（{{i:minecraft:bowl}}）也能上桌：

- **摆在桌上**：和盘子一样摆，一只碗能装 **3 样菜**，当小盘子用。
- **拿碗右键锅**：先盛**熟菜**（最多 3 样）；锅里没熟菜就盛**汤**（汤盛不完，锅里的汤不会少）。
- 装了菜的碗右键锅，整碗倒进锅里。

### 六种汤碗

盛出来的汤是单独的**汤碗**，喝了都回 **4 点饥饿**，还各带效果：

| 汤碗 | 效果 |
| --- | --- |
| {{i:clear_broth_bowl}} | 解除反胃 |
| {{i:rich_stock_bowl}} | 饱和度高，更抗饿 |
| {{i:mushroom_broth_bowl}} | 生命恢复 I，6 秒 |
| {{i:spicy_red_broth_bowl}} | 力量 I，9 秒；但会饥饿 3 秒 |
| {{i:tomato_soup_bowl}} | 生命恢复 I，6 秒；解反胃 |
| {{i:three_fresh_soup_bowl}} | 水下呼吸 15 秒 |

喝完变回空碗，也能摆在桌上。

:::tip
换汤底时**用空桶舀**，一律用桶。菌汤用碗舀成汤碗是另一回事。
:::

## 饮料 {#drink}

{{icons:orange_drink,plant_protein_drink,orient_cola,glass_cup}}

| 饮料 | 每一口的效果 |
| --- | --- |
| {{i:orange_drink}} | 回 2 点饥饿；速度 15 秒；**解辣**（清掉饥饿效果） |
| {{i:plant_protein_drink}} | 回 2 点饥饿；**解辣**，解除反胃 |
| {{i:orient_cola}} | 回 2 点饥饿；速度、急迫各 15 秒；瓶子会冒气泡 |

- 一瓶喝 **4 口**，饱了也能喝，喝完留下**空瓶**，空瓶也能摆桌上。
- 饮料能**摆在桌上**右键喝；提示会写「还剩几口」。
- 三种饮料都有配方了：橙子饮料用橙子，植物蛋白饮料用黄豆，之晗可乐用可可豆和蜂蜜。**橙子**从橡木、深色橡木树叶掉。

### 玻璃杯 {#cup}

{{recipe:glass_cup}}

- 拿饮料右键空杯倒一杯（{{i:orange_drink_cup}}{{i:plant_protein_drink_cup}}{{i:orient_cola_cup}}），**一杯一口**，喝完变回空杯，能摆桌上。
- 瓶子喝完留下**空瓶**（{{i:empty_orange_drink_bottle}}{{i:empty_plant_protein_drink_bottle}}），空瓶能摆桌上，也能拿去舀炼药锅里的饮料。
- **一杯水、一杯牛奶**（{{i:water_cup}}{{i:milk_cup}}）：拿水桶 / 奶桶右键空杯，**桶不会空**；空杯对着水源右键也能舀水。喝水没效果，牛奶清掉所有效果，都不回饥饿。

### 饮料倒进炼药锅 {#cauldron}

- 拿饮料瓶或满杯右键原版**炼药锅**，饮料倒进去：一锅只装一种，最多 **12 口**（3 满瓶），每 4 口水面高一档，水换成饮料的颜色，可乐锅会冒气泡。
- **空杯舀一口**；原版玻璃瓶或这种饮料的空瓶舀**一瓶**（最多 4 口）。舀空变回空炼药锅，倒别的饮料会提示「装的是别的饮料」。

## 筷子 {#chopsticks}

{{recipe:bamboo_chopsticks}}

- **开锅界面**：拿竹筷 **Shift + 右键锅**。
- **从锅里夹熟食**：**直接右键锅**夹起准星那格的一样熟食（没熟食会提示）。
- **从碗、盘子里夹菜**：右键碗或盘子夹走最后放的那样菜。
- **放进锅里**：夹着**生食材**右键锅下锅。
- **吃**：夹着熟菜**按住右键**吃掉（吃饱了吃不下，右键碗或盘子放回去）。蘸过料效果也算上。
- **蘸料**：夹着菜右键桌上的蘸料碗蘸一口，见[蘸料](sauce.html)。
- **架在碗沿、盘沿上**：拿竹筷（夹着菜也行）**Shift + 右键**桌上的碗或盘子，筷子就横躺在碗口上，夹着的菜在正中间；**空手右键**把筷子拿回来（菜还在）。挖掉碗时筷子一起掉。
