# 盘子、碗与饮料

火锅桌上要摆得满满当当：盘子装生菜，碗盛汤，饮料解辣，筷子夹菜。

## 盘子 {#plate}

### 种类

**5 种材质 × 6 种大小 = 30 种盘子**：

| 材质 | 做小碟用的原料 |
| --- | --- |
| 石英 | {{i:minecraft:quartz}} |
| 竹编 | {{i:minecraft:bamboo}} |
| 红陶 | {{i:minecraft:brick}} |
| 铜 | {{i:minecraft:copper_ingot}} |
| 铁 | {{i:minecraft:iron_ingot}} |

| 大小 | 样子 | 能装几样菜 |
| --- | --- | --- |
| 小碟（1×1） | 一格 | 3 样 |
| 双格盘（1×2） | 两格长 | 6 样 |
| 三格长盘（1×3） | 三格长 | 9 样 |
| 四格方盘（2×2） | 方的 | 12 样 |
| 五格长盘（1×5） | 五格长 | 15 样 |
| 八格大盘（2×4） | 大的 | 24 样 |

每一**格**最多装 3 样菜（小碟也是 3 样），所以盘子容量 = 格数 × 3。

### 摆放 {#place}

- 拿着盘子**右键桌面或地面**，盘子就摆在那上面。
- 一格空间里可以**摆好几个**，不能重叠，不同样的可以混着放：小碟一格 5 个、长盘一格 2 个、方盘一格 1 个。
- 盘子会自动贴着桌面：在矮桌上下移 5 像素，在高桌上上移 7 像素。

### 往盘子里放菜、拿菜 {#use}

下面的操作都只作用于**准星对着的那一个盘子**：

| 你手里拿着 | 右键盘子 |
| --- | --- |
| 盘子 | 再摆一个盘子 |
| 食物 | 放一样菜进盘子（一格最多 3 样） |
| 竹筷 | 夹走**最后放的**那样菜；竹筷已经夹着熟菜时再右键盘子 = **吃掉它**，吃饱了吃不下才放回去 |
| 空手 | **把这个盘子（连菜）拿起来** |
| 空手 + 潜行 | 取出最后放的一样菜到背包（盘子留着） |

- **挖盘子**：只挖对着的那一个，盘里的菜会一起掉出来。
- **鼠标中键**：复制准星对着的那个盘子，**连菜一起**。
- 装了菜的盘子，**物品栏图标、手里拿着时**都会画出里面的菜；提示像原版收纳袋，同样的菜合并写「×数量」。
- **端着菜下锅**：拿着装了菜的盘子右键锅，盘里**生的**食材倒进锅里，熟的留在盘子里。

## 碗和汤碗 {#bowl}

### 原版碗也能用

**原版的碗**（{{i:minecraft:bowl}}）也被加了新用法：

- **摆在桌上**：和盘子一样的放法，一只碗能装 **3 样菜**，当小盘子用。
- **用碗右键锅**：先盛**熟菜**（最多 3 样）；锅里没有熟菜，就盛一碗**汤**（汤盛不完，锅里的汤不会减少）。
- 已经装了菜的碗右键锅，整碗倒进锅里。

### 四种汤碗

盛出来的汤是模组自己的**汤碗**物品，喝下去都回 **4 点饥饿**，还各带效果：

| 汤碗 | 效果 |
| --- | --- |
| {{i:clear_broth_bowl}} | 解除反胃（把冷锅吃坏的肚子调理好） |
| {{i:rich_stock_bowl}} | 饱和度高，更抗饿 |
| {{i:mushroom_broth_bowl}} | 生命恢复 I，6 秒 |
| {{i:spicy_red_broth_bowl}} | 力量 I，9 秒；但会饥饿 3 秒（辣的） |

汤碗吃完变回原版的空碗，也能摆在桌上。

:::tip
倒掉锅里的汤（想换汤底）：**用空桶舀**，一律用桶，不管是什么汤。菌汤用碗舀成汤碗是另一回事。
:::

## 饮料 {#drink}

涮火锅怎么能没有饮料？

{{icons:orange_drink,plant_protein_drink,empty_orange_drink_bottle,empty_plant_protein_drink_bottle}}

| 饮料 | 每一口的效果 |
| --- | --- |
| {{i:orange_drink}} | 回 2 点饥饿；速度 15 秒；**解辣**（清掉饥饿效果） |
| {{i:plant_protein_drink}} | 回 2 点饥饿；**解辣**，并解除反胃 |

- 一瓶可以喝 **4 口**，吃饱了也能喝（不受饥饿格限制），喝完留下**空瓶**，空瓶也能摆在桌上。
- 饮料能**摆在桌上**，右键喝；提示会写「还剩几口」。
- 目前饮料**没有合成配方**，在创造物品栏（「食物」标签）里取，或用指令 `/give`。

## 筷子 {#chopsticks}

{{recipe:bamboo_chopsticks}}

筷子是这个模组里最常用的工具：

- **开锅界面**：拿着竹筷，**Shift + 右键锅**。
- **从锅里夹熟食**：**直接右键锅**，从准星对着的那一格夹起一样熟食（那一格没熟食会提示）。
- **从碗、盘子里夹菜**：对着碗或盘子右键，夹走最后放的那样菜（夹着时，筷子尖上会看到那样菜）。
- **放进锅里**：夹着**生**食材右键锅，放进你点的那个大格（下锅）。
- **吃**：夹着熟菜，**按住右键**就吃掉（对着空气、锅、碗、盘子都行；吃饱了吃不下，右键碗、盘子会把菜放回去）。蘸过料的话，效果也会算上。
- **蘸料**：夹着菜右键桌上的蘸料碗，蘸一口，见[蘸料](sauce.html)。
