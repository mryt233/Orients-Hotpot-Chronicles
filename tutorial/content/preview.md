# 开发版预览

:::dev

## 渲染修复 {#render-fix}

- 锅点火升温时，锅内沸腾和气泡不会再出现「先特别快、随后变慢」的跳变；气泡速度随火力平滑变化，稳定后与正式版一致。<!--清单#87-->

## 猪肉末和火腿肠 {#sausage}

{{icons:minced_pork,raw_ham_sausage,ham_sausage,ham_sausage_slice,cooked_ham_sausage_slice}}

1. 把原版**生猪排**放上砧板，**拿铁菜刀右键切一刀**，得 **1 份猪肉末**；切石机也行。擀面杖捣猪肉丸的做法不变。
2. **猪肉末 + 1 个原版小麦**无序合成，出 **3 根生火腿肠**。不需要额外的淀粉物品。<!--清单#72-->
3. 生火腿肠下锅，或用熔炉、烟熏炉、营火加热，得到**火腿肠**，默认回 **3 点饥饿**。开发中原先叫「熟火腿肠」，现在名字和 ID 都改成了「火腿肠」。<!--清单#76-->
4. **火腿肠放砧板上用菜刀切一刀**，出 **3 片火腿肠片**；切石机也能切。**生火腿肠不能放上砧板切**。肠片能直接吃，默认回 **1 点饥饿**，也能摆进碗、盘子。<!--清单#75-->
5. **火腿肠片还能再加热一次**：下锅、熔炉、烟熏炉、营火都行，变成**熟火腿肠片**，默认回 **2 点饥饿**。熟火腿肠片不能再下锅。<!--清单#77-->

{{recipe:minced_pork,raw_ham_sausage,ham_sausage,ham_sausage_slice,cooked_ham_sausage_slice}}

:::tip
顺序记成：**生猪排 → 猪肉末 → 生火腿肠 → 火腿肠 → 火腿肠片 → 熟火腿肠片**。整根煮过才能切，切片以后还能再热一次；别把开发早期的「肠片不能下锅」当成最终玩法。
:::

## 饱了也能吃 {#chopsticks}

{{icons:bamboo_chopsticks,minecraft:bowl,quartz_small_dish}}

- 筷子夹着菜时，**饱食度满了也能吃**：饥饿条不再涨，**饱和度照常加**，最多加到 20。
- **本模组所有食物饱了也能直接拿着吃**（生熟食材、汤碗、毛肚、小葱、香菜等），同样是饥饿条不涨、饱和度照常加到 20。装了 **Always Eat**（让别的模组食物也能饱了吃）不冲突。<!--清单#99-->
- 夹着熟菜**直接右键碗、盘子还是吃**。想放回去，改成**潜行右键**，不再靠「吃饱了自动放回」。
- 架筷子仍是潜行右键碗沿、盘沿，空手右键拿回。**潜行右键有菜先放菜**（把菜放回碗盘，筷子留在手上），**空筷子潜行右键才架筷子**，两项不再互抢；普通右键进食不变。<!--清单#74--><!--清单#84-->

## 管理员可调数值 {#config}

{{icons:hotpot_guide}}

- 游戏会生成 `config/orients_hotpot_chronicles.json`。高级玩家可调整食物营养、汤底速度、燃料和蘸料等数值；管理员执行 **`/orientshotpot reload`** 后立即生效，不用重启。多人服只改服务端，进服和重载时自动同步。配方用数据包改，再执行原版 `/reload`。<!--清单#78-->
- **食物的饥饿值、饱和度也支持热重载**；直接吃、筷子夹着吃、锅界面里吃采用同一份营养数值。缺项或错误数值会分别回退默认值并警告；整个文件写坏时全部用默认值，**坏文件原样保留**方便修复。命令会报告警告条数。<!--清单#81-->

:::tip
教程里的数值是默认值。服务器改过配置后，以服务器的设置为准；配置文件中的说明会写清每项含义、范围和单位。
:::

## 容错和内部整理 {#maintenance}

{{icons:cutting_board,iron_kitchen_knife}}

- **砧板容错**：整合包删掉食材的切石机配方后，砧板仍能用内置做法切；有数据包配方时优先用数据包。<!--清单#73-->
- **子模组扩展点**：为其他子模组预留接口；不装子模组时玩法不变。<!--清单#79-->
- **兼容层整理**：第三方兼容分开加载，某个兼容模块出错只跳过它自己，不影响其他模块；玩家操作不变。<!--清单#80-->
- **标签名翻译**：配方查看器里可显示「可切食材」「需要多刀切的食材」「热源」「可摆桌面的物品」，不用只看原始标签 ID。<!--清单#82-->
- **兼容接线修复**：第三方模组提供的汤底来源、自定义燃料会被实际烹饪逻辑识别，不再只记在兼容层自己的表里；不装第三方模组时玩法不变。具体兼容以实际安装为准，教程不预先承诺。<!--清单#85-->
- **筷子夹菜内部修复**：NeoForge 侧用筷子夹菜不再抛异常，旧存档里夹着菜的筷子照常读出；这是开发工程修复，正式 NeoForge 版还没发布。<!--清单#86-->
- **远距离传送崩溃修复**：死亡重生或被传送到很远的区块后，客户端不会再因为旧区块里残留的灶台而崩溃；已经卸载的锅不会再被客户端继续 tick。<!--清单#88-->
- **服务器卡死修复**：摆了高灶台或蘸料台的服务器，玩家进服、传送时不会再整服卡住。<!--清单#89-->
- **灶膛燃料不再丢失**：灶上没锅时放进灶膛的燃料，重启后还在；灶台、蘸料台界面走远或方块被挖时会自动关上。<!--清单#90-->
- **重启后烹饪时间正确**：重启后锅里没熟的菜按原本的时间继续煮。<!--清单#91-->
- **锅里动画更顺**：点火 / 熄火时锅里轮流显示的菜不会突然换样，气泡在高帧率下也平滑。<!--清单#92-->
- **篝火锅界面火力**：锅放在篝火上煮时，界面显示正在加热、还要几秒，不再显示「没有火」。<!--清单#93-->
- **高灶台挖锅**：站在高灶台上方对着锅挖，只挖下锅。<!--清单#94-->
- **漏斗接锅**：锅上方的漏斗只放进能煮的生食材，锅下方的漏斗只抽走煮熟的菜。<!--清单#95-->
- **饮料营养可调**：服主可以在配置文件里调饮料每口回多少饥饿值；重载命令的提示跟随语言。<!--清单#96-->
- **内部整理**：锅的计算和同步更省资源，玩法不变。<!--清单#97-->
- **锅里换菜更自然**：一格几样菜轮流显示时大小不变，当前这样沉进汤里、下一样浮上来。<!--清单#98-->
- **前置框架整修**：服主重载配置时，每条警告按自己的语言显示并说清原因；Fabric 服务器上客户端和服务器的模组版本对不上时，进服就会提示安装相同版本，而不是进去以后功能不工作。<!--清单#100-->
- **翻译校对**：几种外语的火腿肠名字更准确，zh_tw 教程用词更自然，原版名称对齐官方 zh_tw 译名。<!--清单#101-->
- **加载器接线进度（开发工程）**：1.21.1 主工程已同时接通 Fabric 与 NeoForge 的开发版客户端（锅、灶膛、蘸料界面、火锅指南、渲染、配置同步等）。这只是开发进度，**不代表提供了新的下载**；下载页的正式支持矩阵仍是 0.1.4-alpha（1.21.1 Fabric）和 0.1.3-alpha-hotfix1（1.21.1 NeoForge、1.20.1）。<!--清单#83-->
