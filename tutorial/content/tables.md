# 桌子与凳子

火锅得围着桌子吃。模组里有**两套桌凳**：矮的一套（贴近地面、像家里的火锅桌）和高的一套（1.5 格高、像火锅店的高脚桌），每套都有 **11 种木头**的版本：

{{icons:oak_hotpot_table,spruce_hotpot_table,birch_hotpot_table,jungle_hotpot_table,acacia_hotpot_table,dark_oak_hotpot_table,mangrove_hotpot_table,cherry_hotpot_table,bamboo_hotpot_table,crimson_hotpot_table,warped_hotpot_table}}

橡木、云杉、白桦、丛林、金合欢、深色橡木、红树、樱花、竹、绯红、诡异——桌子的**贴图用的就是原版的木板**，配方也只是把木板换成对应的那种木板。

## 矮火锅桌

{{img:hotpot-low-table.webp|矮火锅桌 + 灶台 + 板凳}}

{{recipe:oak_hotpot_table}}

- 桌面和**矮灶台的砖面齐平**，所以灶台可以直接嵌在一排桌子中间，像一张整桌。
- 桌面下面像倒放的楼梯，朝外一侧往里收 4 像素，给膝盖留出位置。
- **会自己连**：东南西北哪边挨着另一张桌子（矮桌、高桌都行）或灶台，那一侧就铺满，一排排连成长桌。
- 木头的桌子会着火，也能用斧头快速挖。

## 高火锅桌

{{img:hotpot-tall-table.webp|高火锅桌 + 高灶台 + 条凳}}

{{icons:oak_tall_hotpot_table}}

{{recipe:oak_tall_hotpot_table}}

- **1.5 格高**，桌面板悬出一圈，下面 0..19 像素是桌腿，朝外也收进 4 像素。
- 下面一格高是**原版砖块**，上面是木板（所以配方里有 3 个砖块）。
- 和**高灶台**搭配：灶台火口正对着桌子时，桌子在那一侧会**去掉砖身只留木头部分**，这样你能看到灶膛里的火。
- 同样会自己连，和矮桌、灶台都能连。
- 方块比一格高，所以**准星对着桌面上的东西也能选得中**（盘子、碗放在高桌上不会点不到）。

### 桌上摆东西 {#decor}

- **盘子、碗、饮料、蘸料碗**都放在桌面上，见[盘子、碗与饮料](tableware.html)。
- **小摆件**（灯笼、花盆、蜡烛、蛋糕等）放在火锅桌上，会**贴住桌面**，不再浮空。
- 其他普通方块：矮桌上会浮空 5 像素，高桌上会嵌进去 7 像素——按原版方块摆，当装饰也不错。

两种凳子都有 11 种木头，配方只是木板换成对应的木板。

### 摆放

- **朝向**：放的时候你面朝哪边，凳子（和坐上去的人）就面朝哪边。
- **连成长凳**：同一条线上挨着的两个凳子（高矮一样，木头可以不同）会**自己连成长凳**，中间的腿去掉、两头的腿往里收，垂直摆的不会连。0.1.2-alpha 里要**放的时候朝向一样**才连（人站在另一边放就连不上，会错开）；0.1.3-alpha-hotfix1 起不管站哪边，同一条线都会连。
- 条凳的腿是斜着的「A」字腿，由代码画出来（原版模型转不了这么小的角度）。

### 怎么坐 {#sit}

1. **空手**（或手里拿着不是方块的东西）**右键凳子**，就坐上去了。
2. 点凳子**格子的中间**坐中间；点**两格交界处**坐两格中间。
3. 两个人之间**至少隔一整格**，不会挤在一起。
4. **Shift（潜行）**起身，站到凳子的后面。

:::tip
想坐得舒服、吃得顺手：「**条凳 + 高桌 + 高灶台**」是一套，「**板凳 + 矮桌 + 矮灶台**」是一套，别混着搭，高度才对得上。
:::
