# 桌子、备菜架与凳子

火锅得围着桌子吃。模组里有**矮火锅桌**（{{i:hotpot_table}}，贴近地面）与**高火锅桌**（{{i:tall_hotpot_table}}，1.5 格高）、**三种备菜架**（落地架、桌面架、挂架），以及配套的**两套木头凳子**（11 种木头）：

{{icons:hotpot_table,tall_hotpot_table,multi_tier_prep_rack,desktop_prep_rack,hanging_prep_rack}}

- **40 张旧桌子收束为 2 张通用桌**{{since:0.3.1-alpha}}：早期的 11 种木头矮桌、11 种木头高桌和 18 张石料 / 金属桌，现已统一收束为 **{{i:hotpot_table}}** 与 **{{i:tall_hotpot_table}}**，合成配方改用任意原版木板（`#minecraft:planks`），外观通过**换材质**自由搭配。
- **全火锅桌统一不可燃**：木质外观的火锅桌也不会被火焰烧毁。
<!--guide-collapse-->
- **旧存档平滑无损迁移**：更新存档后，**已摆放的旧桌方块**（区块加载时）、**背包里的旧桌物品**（进服时）都会自动平滑迁移并保留原本外观；**箱内旧桌**会原样保留，取出放置时原地无损升级（进背包后重进存档也会自动转换），不会丢档或变紫黑方块。
<!--/guide-collapse-->

## 矮火锅桌

{{img:hotpot-low-table.webp|矮火锅桌 + 灶台 + 板凳}}

{{recipe:hotpot_table}}

- 桌面和**矮灶台的砖面齐平**，灶台能直接嵌在桌子中间，像一张整桌。
- 桌面下面像倒放的楼梯，朝外一侧往里收 4 像素，给膝盖留位置。
- **会自己连**：哪边挨着另一张桌子（矮桌、高桌都行）或灶台就自己铺满，连成长桌；围成方圈或摆出拐角时，转角内侧的砖脚和桌沿也会严丝合缝合拢，不露空洞。
- **统一不可燃**；挖掘速度、破坏粒子与敲击音效跟随当前部位材质，**固定硬度 2.0，空手也可拆下**。

## 高火锅桌

{{img:hotpot-tall-table.webp|高火锅桌 + 高灶台 + 条凳}}

{{icons:tall_hotpot_table}}

{{recipe:tall_hotpot_table}}

- **1.5 格高**，桌面悬出一圈，下面是桌腿，朝外也收进 4 像素留腿部空间。
- 下面一格是**红砖块**，上面是木板（配方里用 3 个红砖块与 3 块任意木板合成）。
- 和**高灶台**搭配：灶台火口正对桌子时，桌子那侧会**去掉砖身只留木头**，方便看火。
- 同样会自己连，和矮桌、灶台都能连，且**统一不可燃**（固定硬度 2.0，空手可拆）。
- 方块比一格高，**准星对着桌面上的东西也能选得中**（盘子、碗放在高桌上不会点不到）。

### 桌上摆东西 {#decor}

- **盘子、碗、饮料、蘸料碗**都放桌面上，见[盘子、碗与饮料](tableware.html)。
- **小摆件**（灯笼、花盆、蜡烛、蛋糕以及{{i:desktop_prep_rack}}等 `table_decorations` 标签内的方块）放火锅桌上会**贴住桌面**，不再浮空。
- 其他普通方块：矮桌上浮空 5 像素，高桌上嵌进 7 像素，当装饰也不错。

## 桌面与底座换材质 {#swap_materials}{{since:0.3.1-alpha}}

{{icons:minecraft:oak_planks,minecraft:bricks,minecraft:quartz_block,minecraft:smooth_stone}}

做好通用**火锅桌**与**高火锅桌**后，无需再按材料分别合成，对着桌子就能直接更换**桌面**和**底座**的材质（**支持其他模组的实心方块**）：

1. **分部位更换（1 进 1 出无损退还）**：手持任意实心方块（完整不透明、非发光、无方块实体且不在黑名单内的方块），**不潜行直接右键**火锅桌：
   - 对着**上半部分**（矮桌桌面及以上 / 高桌桌面及以上）右键，替换**桌面**材质；
   - 对着**下半部分**（桌身 / 底座）右键，替换**底座**材质（高桌连同中圈与底墙整段更换）；
   - 每次消耗 1 个手持方块；若该部位原本已经替换过材质，会把旧材质方块**1 进 1 出无损退还**（默认自带的木板 / 红砖底色不退还）。
2. **潜行操作区分**：
   - **潜行 + 空手右键**对应部位：将已换上的材质方块**无损拆出**并恢复默认外观；
   - **潜行 + 手持方块右键**：豁免换材质判断，按原版方式正常贴桌边搭方块建造。
3. **挖掘手感与保存**：换材质后，桌子的**挖掘速度、破坏粒子与音效跟随当前部位材质**——持续挖掘时指着桌面会溅出桌面材质碎屑，指着底座会溅出底座材质碎屑——且**固定硬度 2.0、空手也可拆**；挖掉掉落或鼠标中键复制都会完整保留已换材质。
<!--guide-collapse-->
4. **旧存档预设说明**：从早期版本 40 张预设桌迁移而来的桌面 / 底座外观会保留，但**不能通过潜行空手拆出方块**（防止刷物），想改外观时**直接手持任意新方块覆盖右键**即可。
<!--/guide-collapse-->
5. **换材质范围配置**：可在设置界面「桌架换材质」或配置文件调整 `table_materials.mode`：
   - `any_solid`（默认）：允许任意符合条件的实心不透明非容器方块（受白名单 `table_materials_allow` 与黑名单 `table_materials_deny` 标签控制）；
   - `tag_only`：只允许白名单标签内的方块；
   - `off`：关闭换材质功能。

## 石料和金属火锅桌 {#stone}{{since:0.1.4-alpha}}

{{icons:minecraft:smooth_stone,minecraft:polished_granite,minecraft:polished_deepslate,minecraft:quartz_block,minecraft:cut_copper}}

0.1.4-alpha 起引入的平滑石头、磨制安山岩 / 闪长岩 / 花岗岩 / 深板岩 / 黑石、石英、切制铜、铁共 **9 种**石料与金属桌面（原 18 张预设桌），自 **0.3.1-alpha** 起已全面并入通用火锅桌的**分部位换材质**系统：做出{{i:hotpot_table}}或{{i:tall_hotpot_table}}后手持对应石料或金属方块右键桌面即可换装，旧存档里原有的石料和金属火锅桌会在加载时自动无损迁移并保留原有外观。

## 三种备菜架 {#prep_racks}{{since:0.3.1-alpha}}

{{icons:multi_tier_prep_rack,desktop_prep_rack,hanging_prep_rack}}

备菜架用来收纳盘子、食材、布围裙和顺手厨具，全部支持**无界面准星分格直接放取**（拿对应物品右键放到准星那格，已有物则顺延到最近空位；空手右键拿回；挖掉会掉出全部已放物品），在开启开关时也同样支持**手持实心方块右键整体换材质**（潜行空手拆出，受 `mode.rack_swap_materials` 与 `table_materials.mode` 控制）：

- **{{i:multi_tier_prep_rack}}（6 格落地架）**：3 层铁木结构，每层 2 格共 **6 格**。可摆放盘子与碗（`#rack_plates` 及桌面物件）以及可直接食用或下锅的食材。
- **{{i:desktop_prep_rack}}（4 格桌面备菜架）**：双层阶梯桌面架（前下 2 格 + 后上 2 格，共 **4 格**）。已加入 `table_decorations` 标签，放在矮火锅桌或高火锅桌上会自动**贴面抬高 / 下沉**紧贴桌面，适合直接摆在桌边备菜。
- **{{i:hanging_prep_rack}}（4 格双态挂架）**：共 **4 格**挂钩，放置时根据点击位置自动切换状态——对着墙面侧面放成 **`wall`（靠墙）**，对着天花板底面放成 **`ceiling`（吸顶）**。专门用于悬挂 `#rack_hangables` 厨具（铁菜刀、擀面杖、竹筷、木压板、剪刀、桶）以及**全部 3 款布围裙**（{{i:cloth_apron}}、{{i:blue_print_cloth_apron}}、{{i:brown_trim_cloth_apron}}）。

## 板凳和条凳

| 凳子 | 高度 | 配方一次出 |
| --- | --- | --- |
| {{i:oak_stool}} | 矮，坐高约 7/16 格 | 3 个 |
| {{i:oak_bench}} | 一格高，凳面和桌面齐平；坐高 1.25 格 | 3 个 |

{{recipe:oak_stool,oak_bench}}

两种凳子都有 11 种木头，配方只是换对应木板。

### 摆放

- **朝向**：放的时候面朝哪边，凳子（和坐上去的人）就面朝哪边。
- **连成长凳**：同一直线上挨着的两个凳子（高矮一样）会**自己连成长凳**，中间腿去掉、两头腿往里收，垂直放的不连。**一条最长连 3 格**，再往旁边放就不连了，不管站哪边放都会连。
- 条凳腿是斜着的「A」字腿，由代码画出来；碰撞与选中范围和凳面同宽，贴着条凳走动不会卡脚。

### 条凳搭起来能当梯子 {#climb}{{since:0.2.2-alpha}}

一条条凳就是一格高，叠起来正好是一级级台阶。

1. **手拿条凳（不潜行）右键已经放好的条凳**，它会自动顺着这一摞往上找，直接叠到**最顶上**，一次消耗 1 条。
   - 也可以直接对着凳子的**顶面**放，效果一样。
   - 最多叠 **16 层**，再高就放不上了。
2. 叠到 **2 层以上**，这一摞就成了**梯子**：贴着凳子**任意一面**往前走或按跳跃，就能像爬梯子一样一级级上下。单摆一张不会触发，免得围着桌子走动时不小心爬上去。
3. **顶层照样能坐**：空手右键最上面那张，坐姿和普通条凳一样。中间层（头顶还压着凳子）坐不了。
4. 坐着的时候别人往你头顶叠凳子，你会自动起身，把位置让出来。
5. 拆凳子照常挖，坐在上面的人会被放下。

{{icons:oak_bench,bamboo_bench}}

:::tip
叠条凳顺手，拆也顺手：想够高处的东西、想在火锅桌边搭个「上铺」，几条凳子就够。把条凳往条凳上叠、或者顺着凳塔往上爬，都会解锁成就「**步步高升**」。
:::

### 怎么坐 {#sit}

1. **空手**（或手里拿不是方块的东西）**右键凳子**就坐上去了。
2. 点凳子**中间**坐中间；点**两格交界处**坐两格中间。
3. 两个人之间**至少隔一整格**，不会挤在一起。
4. **Shift（潜行）**起身，站到凳子后面。

:::tip
搭配推荐：「**条凳 + 高桌 + 高灶台**」是一套，「**板凳 + 矮桌 + 矮灶台**」是一套，别混着搭，高度才对得上。
:::
