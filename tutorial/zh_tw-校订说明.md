# zh_tw 用语校订与维护

公开网页的语言名称统一显示 `zh_tw`，文件名采用 `_zh_tw.html`。HTML 的 `lang="zh-TW"` 保留标准语言代码，供浏览器与辅助阅读工具识别，不使用地区名称作为网页标签。

正文独立维护在 `content-zh-tw/`，不在构建时进行逐字简繁转换。此次校订覆盖十篇手写正文，以及自动生成的配方、图鉴、目录、图注、物品提示与搜索提示。

| 语境 | zh_tw 用语或处理 |
| --- | --- |
| 电脑操作 | 滑鼠、游標、介面、圖示、資料夾、連線、伺服器端 |
| 文字操作 | 連按兩下、複製、問題回報、螢幕截圖、當機報告 |
| 日常饮食 | 沾醬、醬料台、青蔥、擀麵棍、馬鈴薯、柳橙飲料 |
| 状态效果 | 噁心、回復、加速、挖掘加速、劇毒；不把“速度”效果与烹调速度混淆 |
| 原版物品与附魔 | 熔岩桶、鮮奶桶、蘑菇湯、地獄石英、鵝卵石、掠奪、矮草、芒草 |
| 材料查找 | 杉木／雲杉木、相思木／金合歡木、黑橡木／深色橡木等对照写在桌椅章节 |
| 模组现有名称 | 配方、图鉴和物品图标的名称取游戏 `zh_tw.json`；正文解释蘸料／沾醬、小蔥／青蔥、板凳／矮凳、條凳／長凳的对应关系 |
| 牛肉名称 | 保留牛脊肉与吊龍，不擅自替换为其他牛肉部位 |
| 饮品名称 | 不把植物蛋白飲料改称豆漿；橙子飲料保留游戏名并解释常用说法 |

原版物品名来源为本机缓存的 Minecraft 1.21.1 `minecraft/lang/zh_tw.json`；指南使用的 39 个名称裁剪到 `data/vanilla_zh_tw.json`。模组本身的语言档和游戏内容均未修改。

正文的数字、配方指令、物品 ID、版本标记、图片路径、链接及锚点均已与简中来源核对。原教程的 0.1.2-alpha 基准和 0.1.3 预告保留；这次是语言校订，没有改写游戏规则。

维护步骤：先同步简中正文及 zh_tw 正文，再运行 `python tools/build_tutorial_tw.py`，最后运行 `python tools/build_tutorial_bilingual.py` 合并三语。两种生成器均检查公开语言标识，避免引入不符合本次要求的名称。
