# Orient's Hotpot Chronicles | 之晗的火锅物语

A Minecraft mod inspired by Chinese hotpot culture, featuring interactive hotpot cooking.

一个以中华火锅文化为主题的 Minecraft 模组，包含灶台、铜锅与铁锅、九宫格烹饪、不同汤底及筷子交互。

## Compatibility / 运行要求

- **Minecraft:** 1.21.1
- **Mod loader:** Fabric
- **Java:** 21
- **Fabric API:** Required / 必需
- **Current source version:** `1.0.0-r39`

## Features / 主要玩法

- Cook food with fuel-powered stoves / 在灶台中加入燃料烹饪食物
- Place iron or copper hotpots / 使用铁锅或铜锅
- Choose clear, milky, mushroom, or spicy soup bases / 选择清汤、浓汤、菌汤或红汤
- Interact with a 9×9 hotpot grid using chopsticks / 用筷子操作 9×9 火锅食材格
- Optional integration hooks for other food-related mods / 预留其他食物类模组的可选兼容接口

## Build / 构建

The project uses Fabric Loom and Gradle. JDK 21 is required. If your checkout does not include the Gradle Wrapper, install a compatible Gradle version (the project handover notes mention Gradle 8.12.1).

该项目使用 Fabric Loom + Gradle，需使用 Java 21。当前交付的源码不含 Gradle Wrapper；可使用兼容的 Gradle 版本进行构建。
