# 移植同步清单

（作者：，2026-10-23 建。用户要求：主工程每次游戏内的改动、更新、修复都详细记在这里，移植到其他版本的对话靠它同步，防止漏改。）

## 怎么用

**主工程（1.21.1 Fabric，`mod/`）这边**
- 每做完一项游戏内的改动（新内容、改数值、改外观、修 bug、改 ID、改交互），就往最上面「未发布」那一段加一条。
- 用户打包发布正式版时（`Releases/`，例如 0.1.2-alpha），把「未发布」改名为那个版本号，再在上面新开一段「未发布」。

**移植那边（`version-ports/`，见 `version-ports/移植表.md`）**
- 移植**只用已发布的正式版**，不拿开发版（r104、r106 这类）去移植。
- 同步到某个正式版时，把这里**该版本那一段**逐条做完，每条后面的「移植注意」写的是 1.20.x / Forge / NeoForge 上要换写法的地方。
- 每条做完后，在移植表的「同步记录」里记下来，防止漏掉。
- 想看每条的来龙去脉、用户原话，查 `mod/DEV_LOG.md` 里对应的开发版号（rN）。
- 加新东西的交互规矩（中键复制、选中框、东西超出一格、改 ID 兼容）见 `mod/docs/交互规范手册.md`，移植版也要照做。

**玩家教程**（新增，2026-10-24）：这份清单每加一条，同时要把它写进 `mod/tutorial/content/changelog.md` 的「开发版（未发布）」，条目后面带 `<!--清单#编号-->`，并更新受影响的教程章节；`python tools/build_tutorial.py` 会检查有没有漏。

**每条的写法**
- **玩家看到的**：游戏里有什么变化、数值是多少。
- **改了哪里**：Java 类、资源、数据文件、生成脚本。
- **移植注意**：哪些写法在别的 MC 版本 / 加载器上不一样（没有就写「无」）。

  - Java：`hotpot/CuttingBoardBlock`、`CuttingBoardBlockEntity`（存 `Item` + `Cuts`），`client/CuttingBoardRenderer`；`HotPotContent` 里的物品注册（`foodItem(...)`）。
  - 标签：物品标签 `cuttable`（能放上砧板切的）、`cut_piece_by_piece`（一刀一份的：土豆）；肉卷加进 `minecraft:meat`。
  - 生成脚本：`tools/gen_cutting.py`（砧板、菜刀、肉卷，含配方 / 标签 / 掉落）、`tools/gen_ingredients.py`（土豆片、黄豆、豆腐）。
  - 语言：`CUTTING_TEXT`、`POTATO_TOFU_TEXT`。
- **移植注意**
  - 砧板查切石机配方：1.21 是 `getFirstMatch(RecipeType.STONECUTTING, new SingleStackRecipeInput(stack), world)` → `RecipeEntry`；1.20.x 用 `SimpleInventory` 当输入，1.20.1 直接是配方本身（同移植表的熔炉配方差异）。
  - 数据文件夹 / 配方 JSON 格式差异同移植表（`recipe/` → `recipes/`，结果 `"id"` → `"item"`）。
  - `stack.damage(1, player, LivingEntity.getSlotForHand(hand))` 在 1.20.x 是 `damage(1, player, p -> p.sendToolBreakStatus(hand))`。
  - 菜刀的攻击属性用的是 1.21 的 `attributeModifiers` 物品设置，1.20.x 要改成重写 `getAttributeModifiers`。

#### 3. 丸子 + 擀面杖（r105，r106 后又调）
- **玩家看到的**
  - **擀面杖** `rolling_pin`（开发中曾叫木棒 `wooden_pounder`，已改名）：原木在上、木棍在下；耐久 120。

  - **丸子**：`beef_meatball`、`pork_meatball`、`mutton_meatball`、`fish_ball`。

    - 熟的是 `cooked_` 开头，例如 `cooked_cilantro_fish_ball`。
    - 饥饿值：生的 1；熟的 3；熟的香菜版 4。
    - 肉丸（不含鱼丸）进 `minecraft:meat`。
  - **样子**：丸子是**立体小圆球**（直径 6 像素），锅里、手里、盘里、物品栏都是 3D 的。
- **改了哪里**
  - Java：`hotpot/Pounding`；`CuttingBoardBlock` 里的擀面杖分支；隐藏物品 `pounded_meat`（不进创造栏，用「自定义模型数据」1..8 换成牛 / 猪 / 羊 / 鱼 × 碎肉 / 肉浆的样子，给砧板渲染器画立体用）。
  - 生成脚本 `tools/gen_meatballs.py`：丸子的 3D 物品模型、贴图、阶段贴图、配方、标签。
  - 语言：`MEATBALL_TEXT`。
- **移植注意**
  - 「自定义模型数据」是 1.21 的 `DataComponentTypes.CUSTOM_MODEL_DATA`，1.20.x 用 NBT `CustomModelData`；物品模型里的 `overrides` 写法两边一样。

### 修复

#### 10. 旧存档里灶台、盘子、凳子消失（r106）
- **玩家看到的**：0.1.0-alpha.1 的存档进新版本，东西能自动认回来。
  - 例外：旧板凳 `<木头>_bench` 的名字现在被条凳占用了，会读成条凳。
- **改了哪里**：`hotpot/LegacyIds`（旧 ID → 新 ID 对照表，55 条，来源 `tools/rename_ids.py`）；`mixin/LegacyIdRegistryMixin`、`mixin/LegacyIdDefaultedRegistryMixin`（方块 / 物品注册表按 ID 查时换成新 ID）。
- **移植注意**
  - 移植版都是从 0.1.1-alpha 开始的，0.1.1-alpha 已经是新 ID，所以**只有**玩家会拿 0.1.0-alpha.1 存档去玩的版本才需要。
  - 注册表类和方法名各版本不同：1.20.x 的 `SimpleRegistry` / `DefaultedRegistry` 方法签名要对一遍；Forge / NeoForge 有自带的旧 ID 重映射机制，可以改用那个。

#### 11. 桌上的饮料 / 菜中键复制不了，准星选中的是桌子（r106）
- **玩家看到的**：矮火锅桌上的盘子、饮料，对着下半截也能选中、中键复制、右键操作。
- **原因**：矮桌上的盘子底面比自己那一格低 5 像素，沉进了桌子那一格。
- **改了哪里**：`hotpot/TallReach` 增加「每格也看上面那格垂下来的部分」；盘里有菜时盘子的选中 / 碰撞高度加 2.5 像素（`PlateHolderBlockEntity.FOOD_H`、`partShape`）。
- **移植注意**：`TallReach` 由 `mixin/EntityRaycastMixin` 调用，各版本射线方法签名对一下即可。

#### 12. 灶台上的锅中键复制成了灶台（r106）
- **玩家看到的**：对着锅复制锅，对着灶身复制灶台；高灶台上半截同理。
- **改了哪里**：`StoveBlock.getPickStack`（用 `aimsAtPot`）、`StoveTopBlock.getPickStack`、`CuttingBoardBlock.getPickStack`（对着板上的东西复制那样东西）。
- **移植注意**：`getPickStack` 的参数 1.20.1 是 `BlockView`，1.20.4 起是 `WorldView`（见移植表）。

#### 13. 选中框把一格里的东西全框上（r106）
- **玩家看到的**：准星对着哪样只框哪样：灶台和锅分开框，一格里几个盘子只框对着的那个，砧板和板上的东西分开框。
- **改了哪里**：新接口 `hotpot/PartOutline`（方块返回「对着的那一部分」的形状）+ `client/PartOutlineRenderer`（Fabric `WorldRenderEvents.BLOCK_OUTLINE` 接管画框）。实现的方块：`StoveBlock`、`StoveTopBlock`、`PlateHolderBlock`、`CuttingBoardBlock`。
- **移植注意**
  - 1.20.x Fabric 有同名事件；画线的顶点写法 1.20.x 要加 `next()`。
  - Forge / NeoForge 用 `RenderHighlightEvent.Block`（取消原版框后自己画）。

#### 14. 火锅界面、灶台界面里指着东西看不到名字和属性（r104）
- **改了哪里**：`client/HotPotScreen`、`client/StoveScreen` 加 `render` 重写并调用 `drawMouseoverTooltip`（原版 `HandledScreen.render` 不会自己画悬停提示）。
- **移植注意**：1.20.x 的 `HandledScreen` 同样要自己调；如果移植版已经有这一步就不用改。

#### 15. 高火锅桌不会着火（r107）
- **玩家看到的**：11 种木头高火锅桌和矮桌、板凳、条凳一样会着火（可燃 5 / 20）；绯红、诡异的不燃。
- **改了哪里**：`HotPotContent.register` 里给 `TALL_TABLES` 登记 `FlammableBlockRegistry`。
- **移植注意**：1.21.1 NeoForge、1.20.1 Forge 移植版已经是这样；1.20.1 / 1.20.4 Fabric 移植版要补上（见 `version-ports/移植表.md` 差异表）。

#### 16. 木头蘸料台、砧板会着火（r107）
- **玩家看到的**：11 个木头蘸料台、砧板可燃 5 / 20；铁蘸料台、绯红 / 诡异的不燃。
- **改了哪里**：`HotPotContent.register` 里的 `FlammableBlockRegistry`（蘸料台和 `TABLE_WOODS` 同序；看不见的上半截不登记）。
- **移植注意**：随第 1、2 条一起做；Forge / NeoForge 用方块的 `isFlammable` / `getFlammability` 或各自的可燃登记。
