# 新物品 / 新贴图工作流

作者：mryt233（2026-11-01）。用户不动手，只看对比板选编号；下面每一步都由开发者执行。

## 一、新加一样东西

1. **写描述文件**：`python tools/new_item.py --example > 某物.json`，改成要做的东西（ID 跟英文名走；10 种语言写全，zh_tw 可省；数值、熟的版本、砧板切法、指南文字）。
2. **预演**：`python tools/new_item.py 某物.json`，看清单里每个文件改什么。有「✗」先改描述文件（比如这样东西在砧板上已经能切出别的了）。
3. **写入**：`python tools/new_item.py 某物.json --apply --compile`。它会注册代码、加创造栏、写语言（zh_cn / en_us 直接写，其余写进 `tools/lang_items.json` 再跑 `gen_lang.py`）、模型、占位贴图、熔炉 / 烟熏炉 / 营火配方（锅里能煮就靠这三条）、切石机配方 + cuttable 标签 + 砧板内置表、指南（`tools/guide_items.json` → `gen_guide_book.py`）、教程图标、查看器分类、内容清单，最后编译 + `check_all`。
4. 占位贴图会被贴图自检标出「对比度太低」，**这是提醒还没画正式贴图**，画好就消失。

## 二、画贴图

1. **先查原版**：`python tools/vanilla_ref.py find --like beef`（同类原版的色板、明暗级数、描边）、`ramp 生肉`（直接取色）、`profile 熟肉`（颜色数 / 对比度范围）、`sheet 熟肉`（放大拼图直接看）。
2. **用 pixkit 画**：`from pixkit import canvas, color, io`。色阶 `color.ramp`、球面明暗 `canvas.sphere_level`、描边 `outline_outer`、颗粒 `speckle`、照原版换色 `recolor_by_luma`。说明见 `tools/pixkit/README.md`。新脚本不要再自己写 mix / shade / outline / write。
3. **自检**：`python tools/check_textures.py --file 候选.png --as item/某物`。错误必须改；警告要么改，要么在 `tools/texture_allowlist.json` 写明原因。
4. **出对比板**：`python tools/compare_board.py 某物 --as item/某物 --png 1.png 2.png 3.png`（方块模型用 `--model 引用 --root 候选目录...`）。输出 `build/boards/某物.png`，用文件卡片发给用户，用户回「2 号」。
5. 用户选定后把那一版写进生成脚本 / 装进模组，跑 `python tools/check_all.py`。

## 三、改旧生成脚本

改到哪个 `gen_*.py` 就顺手迁到 pixkit。迁移前后资源指纹必须完全一致（只允许 CRLF → LF），做法见 `tools/pixkit/README.md`「迁移旧脚本的规矩」。

## 工具一览

| 工具 | 做什么 |
| --- | --- |
| `tools/pixkit/` | 画图公共库（颜色、画布、模型、写文件、动画、贴图统计、中文字体） |
| `tools/vanilla_ref.py` | 原版 1.21.1 贴图参考库（1617 张，按分类查色板 / 明暗 / 描边） |
| `tools/check_textures.py` | 贴图自检（已接进 `check_all.py` 第 6 项） |
| `tools/compare_board.py` | 方案对比板（给用户选编号） |
| `tools/new_item.py` | 新物品脚手架 |
| `tools/gui_center.py` | 方块样式物品图标在物品栏里居不居中（自检也用它） |
| `tools/render_preview.py` | 方块模型离线斜视渲染（对比板也用它） |

测试：`python tools/tests/test_pixkit.py`、`test_check_textures.py`、`test_compare_board.py`。
